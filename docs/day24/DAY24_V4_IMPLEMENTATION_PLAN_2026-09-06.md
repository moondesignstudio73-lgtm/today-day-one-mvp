## 핵심 불변식

- DAY23 대화 합의가 없거나 현재 거절되면 카페 대면을 만들지 않는다.
- 관계 지속, 유예, 종료는 서로 다른 상태다. 유예는 계속 사귀는 것으로도 즉시 이별한 것으로도 임의 해석하지 않는다.
- 하은의 대답은 여행 만족도, 호감 수치, 주인공 선택으로 자동 결정하지 않는다.
- 현재 접촉 동의 없는 위로 포옹·손잡기·어깨 기대기를 자동 재생하지 않는다.
- 나리의 명함과 업무 접점은 연애 연락으로 바꾸지 않는다.
- 이미 DAY23에서 정정한 연락을 DAY24에서 다시 정정하지 않는다.
- 관계 상태에 관한 거짓말은 명시적인 기만 fact로 남기되 자동 발각·자동 용서·자동 파국을 만들지 않는다.
- 새 타인 만남은 현재 관계가 끝나기 전에는 열지 않으며, 상대의 수락 전에는 일정으로 확정하지 않는다.
- 상호 지속과 C14 수락이 모두 없으면 DAY25의 하은 미래 대화를 확정하지 않는다.
- Renderer에는 실제 대사·독백·필요한 player narration만 전달한다. `~인 경우`, `~경로에서는`, `장면이 생기지 않는다` 같은 분기 설명과 편집 메모를 일반 대화창에 출력하지 않는다.
- 조건을 만족하지 않는 사람·장소·물건·과거 사건의 부재를 설명하기보다 현재 실제 행동과 관찰을 쓴다.
- Story Choice 진행 중 legacy DAY24 Free Action을 열지 않는다.
