## 이번 구현

SCENE04에서 나눠 먹기를 제안한 뒤 원문 “유리 씨가 잠깐 생각했다.”를 대화창 문장이 아닌 600ms `storyPause`로 연결했다. 이후에야 “조금은 좋아. 그런데 나 이거 꽤 먹을 거야.”가 나온다. 선택 즉시 동의한 것처럼 응답하지 않으며, 생각하는 시간 자체를 수락/친밀감 flag로 기록하지 않는다. 원문의 “절반 계약은 아닌 걸로.”와 구두 약속 대사는 그대로 유지한다.

입력은 기존 `dinner=YURI`, `menu=menu_share`이다. 출력 상태나 저장 스키마를 추가하지 않는다. 기존 장면 그래프의 메뉴 선택 → 짧은 응답 대기 → 유리의 제한적 수락 → 다음 대화 연결만 보완한다. 하은 및 각자 고르기/더 보기에는 이 유리 응답 앵커가 없다.
