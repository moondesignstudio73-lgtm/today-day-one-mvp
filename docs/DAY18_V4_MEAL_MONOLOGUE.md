# DAY18 SCENE12 독백 복구 계약

원문 “멀쩡한 식사를 두고 굳이 관계에 대한 교훈을 붙이지는 않았다.”는 행동 지시가 아니라 주인공의 해석/내적 태도다. 식사 평가 뒤 파일 소동 앞에 명시적 `monologue`로 복구한다. sourceNote 전체를 독백으로 바꾸지 않는다.

입력: 실제 하은 식사의 세 메뉴 선택. 출력/flag/장면 그래프 변경 없음. 유리/혼자/취소에는 출력하지 않는다. 단위 검사와 실제 브라우저로 순서를 확인한다. 상대 음식 맛보기와 각자 먹기는 별도 미완료 행동이며 이 독백으로 구현을 대신하지 않는다.
