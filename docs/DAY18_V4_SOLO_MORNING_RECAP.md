# DAY18 SOLO 아침의 답장 회고 조건 수정

2026-09-05 00:39 실행. game209 / bridge21 / playable21. DAY18 PARTIAL.

DAY17 실제 `life_solo`/`life_open` 선택 반응은 개인 결정이며 식사 약속에 답장을 보냈다는 사실을 보장하지 않는다. DAY18 입력은 SOLO에 유리 거절/유보·하은 약속 불가도 합치므로 SOLO라는 값만으로 특정 답장을 회상하면 안 된다. 원문 SCENE01의 '아무에게도 약속하지 않았다면 저녁 칸은 비어 있었다'와 대조했다.

물잔 CG 다음의 `휴대전화에는 어제 내가 보낸 답이 남아 있었다.`를 확정된 YURI/HAEUN 약속에만 표시한다. SOLO에서는 바로 빈 저녁 칸과 비교하는 마음으로 이어진다. 유리에게 실제 거절한 메시지가 없었다고 부정하지도 않는다. 특정 메시지의 존재를 확정하지 않는 보수적 표현이다. 기존 frozen input / 선택 / 저장 스키마 / 연락 이력은 수정하지 않았다.

검증: 3개 저장 스키마 × 3상대의 기존 아침 테스트에 조건을 추가, 전체 465 PASS. diff 검사 통과. 실제 SOLO 아침을 비-SKIP으로 진행하여 물잔 CG 직후 빈 저녁 칸 → 비교 독백 → 혼자 선택 1개/08:00 확인. 콘솔 오류·경고 없음. 테스트 전 사용자 저장 복원 완료. 전체 경로 및 중간 reload 재검증은 이번 실행에서 하지 않았다.
