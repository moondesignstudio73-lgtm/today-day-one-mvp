# DAY18 SCENE02 미전송 초안

2026-09-05 02:01 실행, game218. DAY18 PARTIAL.

원문의 ‘저녁’ 단어를 쓰다가 지우는 행동을 `messageDraft` 이벤트로 연결했다. 하은의 점심 메시지 → ‘저녁’ 미전송 초안 → 클릭/Enter로 단어 삭제 → 빈 초안 → 답장 선택의 흐름이다. 기존 개인 문서 패널의 레이아웃/입력/정리 수명주기를 재사용하되 제목과 미전송 표시, 접근성 버튼 이름을 분리했다. 일반 대화 로그에 행동 설명을 추가하거나 초안을 실제 문자로 보내지 않는다.

입력/출력/schema는 변경하지 않는다. 연락 휴식 경로는 기존처럼 점심 연락 장면에 진입하지 않으며 초안도 없다. 원문에 없는 전체 문장을 만들지 않고 지정된 단어만 보여준다. 자유 입력 편집기가 아니라 원문 동작을 진행하는 두 단계 연출이다. AUTO는 기존 문서 진행 규칙을 따른다.

## 검증 및 수정

- 렌더 VM 검사: 초안의 HTML escaping, 미전송 제목, 삭제 전/후 버튼 이름, 대화 타이핑/발송 부작용 없음. 기존 메모 회귀 유지.
- 경로 검사: 유효한 약속/연락 조합에서 초안 두 단계와 상태 순수성/JSON 재생. 첫 시험에 잘못 만든 ‘하은 약속 수락+연락 불가’ fixture는 저장 계약이 정상 거부했으므로 유효 조합으로 바로잡았다. 런타임 검증기를 완화하지 않았다.
- 실제 SOLO 비-SKIP: 아침→점심 초안 표시/12:30, Enter 삭제, 답장 선택 복귀, 새로고침 재개 확인.
- 실제 QA에서 초안 종료 후 기존 문자가 일반 대화 형태로 바뀌는 문제를 찾아 수정했다. 초안 아래 이전 하은 문자 스타일을 유지하고 재검증에서 ‘문자 · 하은’으로 복귀함을 확인했다.
- 콘솔 오류/경고 없음. 같은 QA 탭에서 사용자 저장 복원 완료.
- 최종 전체 자동 테스트 474 PASS, 0 FAIL. 구문 및 diff 검사 통과.

다음은 새 초안의 SKIP/유리·하은 분기 확인 및 SCENE02 남은 행동 검토다. 알람 직접 입력/소리와 최종 동일 버전 4경로/모바일·DAY15~17 감사는 남아 있다. DAY19~30 원본은 미완료다.

## 02:09 초안 SKIP 후속

game218 하은 약속 유지 경로에서 아침부터 초안까지 비-SKIP 진행했다. ‘저녁’이 있는 초안에서 SKIP → 초안 패널 제거/일반 진행 버튼 이름 복구/12:30/‘문자 · 하은’ 유지/‘이따 만나서 얘기하고 싶어’ 단일 선택을 확인했다. 새로고침/이어하기 후 같은 구간에서 단어를 지운 빈 초안에서도 SKIP을 반복해 같은 정리를 확인했다. 선택을 임의 확정하지 않았고 자유행동 UI도 나타나지 않았다.

콘솔 오류/경고 없음, 같은 QA 탭의 원래 저장 복원 확인. 이 시험은 의도적인 SKIP 회귀 시험이며 비-SKIP 원문 완주와 분리한다. 런타임 변경 없음. 다음은 유리 초안 분기 확인 후 SCENE02 남은 밥 확인 행동/다음 장면 행동 감사다.
