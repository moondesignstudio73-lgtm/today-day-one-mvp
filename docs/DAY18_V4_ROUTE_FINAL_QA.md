# DAY18 V4 4성향 실제 경로 최종 QA

## 판정

진행 중. game247에서 Friendly, Neutral, Distant 3경로를 실제 브라우저로 완료했다. Mixed는 아직 실행하지 않았으므로 DAY18 전체 완료로 판정하지 않는다.

## Friendly — PASS (2026-09-05)

- 진입: DAY17 완료 fixture의 `하은과 저녁`, 실제 `불러오기`로 DAY18 시작.
- 조작: SKIP 버튼을 한 번도 사용하지 않고 대화창 클릭, 알람 정지, 모든 선택지를 직접 선택했다.
- 주요 선택 흐름: 하은과 약속 유지 → 함께 저녁 → `오늘 너랑 이렇게 있는 게 좋아.` → `옆으로 가도 돼?` → `오늘 너랑 먹어서 좋았어.` → `하루 어디 다녀오고 싶어.` → `가까운 데서 하루 보내는 걸 보자.`
- 연출 확인: 아침 입력, 하은 저녁 19:00, 옆자리 동의 뒤 거리 변화, 22:00 문자, 평온한 밤 대화, 방 행동과 최종 암전 뒤 DAY19 금요일 전환.
- 상태 경계: 다른 사람에게 실제 관심이 없는 fixture에서 다른 마음을 발언하거나 존재하지 않는 연락·합의를 생성하지 않았다.
- 결과: DAY19 진입 PASS, 브라우저 콘솔 error/warn 0.
- 저장: fixture가 만든 QA 저장을 테스트 전 사용자 저장으로 복원했다.

## Distant — PASS (2026-09-05)

- 진입: DAY17 완료 fixture의 `혼자 저녁`에 `하은 연락 휴식` 입력을 켠 뒤 실제 `불러오기`로 DAY18 시작.
- 조작: SKIP 버튼 없이 대화창 클릭, 알람 정지, 6개 선택지를 직접 선택했다.
- 선택 흐름: 혼자 저녁 → 익숙한 김밥 → 휴대전화 없이 식사 완료 → 바로 귀가 → 오늘은 더 연락하지 않기 → 현재 생활 후보.
- 연출 확인: 19:00 혼자 식당, 휴대전화/추가 식사/봉투 행동, 바로 귀가, 22:00 혼자 방, 방 행동·암전 뒤 DAY19 전환.
- 상태 경계: 연락 휴식 입력에서 하은 낮 메시지와 밤 연락 선택이 나오지 않았고, 식당·귀가 구간의 `#vnCharacter` 비노출을 확인했다. 갑작스러운 갈등·연락 의무·동행 약속을 만들지 않았다.
- 결과: DAY19 진입 PASS, 브라우저 콘솔 error/warn 0.
- 저장: fixture가 만든 QA 저장을 테스트 전 사용자 저장으로 복원했다.

## Neutral — PASS (2026-09-05)

- 조작: SKIP 버튼 없이 대화창 클릭, 알람 정지, 11개 선택지를 직접 선택했다.
- 선택 흐름: 약속 유지 → 하은에게 유리 저녁 사전 고지 → 각자 메뉴 → 과거 이야기 → 고마움 → 하은과 현재 관계 명시 → 당분간 시간 두기 → 각자 결제 → 하은에게 사실 보고 → 확신 유보 → 현재 생활 후보.

- 결과: DAY19 진입 PASS, 브라우저 콘솔 error/warn 0.
- 저장: fixture가 만든 QA 저장을 테스트 전 사용자 저장으로 복원했다.
