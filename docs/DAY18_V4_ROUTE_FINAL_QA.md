# DAY18 V4 4성향 실제 경로 최종 QA

## 판정

진행 중. game247에서 Friendly, Neutral, Distant, Mixed 네 경로를 실제 브라우저로 완료했다. 분기별 저장 재개와 모바일 최종 비교가 남았으므로 DAY18 전체 완료로 판정하지 않는다.

## Friendly — PASS (2026-09-05)

- 진입: DAY17 완료 fixture의 `하은과 저녁`, 실제 `불러오기`로 DAY18 시작.
- 조작: SKIP 버튼을 한 번도 사용하지 않고 대화창 클릭, 알람 정지, 모든 선택지를 직접 선택했다.
- 주요 선택 흐름: 하은과 약속 유지 → 함께 저녁 → `오늘 너랑 이렇게 있는 게 좋아.` → `옆으로 가도 돼?` → `오늘 너랑 먹어서 좋았어.` → `하루 어디 다녀오고 싶어.` → `가까운 데서 하루 보내는 걸 보자.`
- 연출 확인: 아침 입력, 하은 저녁 19:00, 옆자리 동의 뒤 거리 변화, 22:00 문자, 평온한 밤 대화, 방 행동과 최종 암전 뒤 DAY19 금요일 전환.
- 상태 경계: 다른 사람에게 실제 관심이 없는 fixture에서 다른 마음을 발언하거나 존재하지 않는 연락·합의를 생성하지 않았다.
- 결과: DAY19 진입 PASS, 브라우저 콘솔 error/warn 0.
- 저장: fixture가 만든 QA 저장을 테스트 전 사용자 저장으로 복원했다.

## Mixed — PASS (2026-09-05)

- 진입: DAY17 완료 fixture의 `유리와 저녁`에 `하은에게 유리 약속을 아직 말하지 않음` 입력을 켠 뒤 실제 `불러오기`로 DAY18 시작.
- 조작: SKIP 버튼 없이 대화창 클릭, 알람 정지, 12개 선택지를 직접 선택했다.
- 선택 흐름: 약속 유지 → 상대 미고지 → 각자 메뉴 → 현재의 유리에게 관심 → 과거 외로움 공감 → 하은과 현재 관계 명시 → 재만남 요청 → 각자 결제 → 하은에게 사실 보고 → 내일 가능한 시간 다시 묻기 → 개인 메모 → 부산 시간·비용 후보.
- 상태 경계: 유리의 재만남 답변은 `REQUESTED_NOT_ACCEPTED`로 유지됐고, 하은과 통화 시각 합의·여행 동의를 생성하지 않았다. 개인 메모는 전송되지 않았다.
- 연출 확인: 유리 식당/야외 작별, 22:00 미고지 사실 보고, 통화 연기, 혼자 방과 개인 메모, 여행 사진·부산 후보, 암전 뒤 DAY19 전환.
- 결과: DAY19 진입 PASS, 브라우저 콘솔 error/warn 0.
- 저장: fixture가 만든 QA 저장을 테스트 전 사용자 저장으로 복원했다.

## 저장 재개 — 유리 저녁 PASS (2026-09-05)

- 진입: 결제 후 야외 작별 집중 fixture를 실제 `불러오기`로 시작했다.
- 새로고침 전: `yuri-outerwear-close` 겉옷 여밈 뒤 `유리: 잘 들어가.` → `나: 유리 씨도요.` → 인물 숨김 순서를 SKIP 없이 확인했다.
- 저장 재개: 작별 진행 중 페이지를 새로고침한 뒤 실제 `불러오기`를 눌러 같은 Scene 시작부터 재생되는 계약을 확인했다. 겉옷 여밈, 두 작별 대사와 인물 표시가 같은 순서로 복구됐다.
- 범위: 정확한 대사 오프셋 복원이 아니라 프로젝트가 채택한 Scene-start 복구 계약에 대한 PASS다.
- 결과: 브라우저 콘솔 error/warn 0, fixture 종료 후 테스트 전 사용자 저장 복원 PASS.

## 저장 재개 — 하은 밤 PASS (2026-09-05)

- 진입: 연락 가능한 밤 통화 집중 fixture를 실제 `불러오기`로 시작했다.
- 새로고침 전: 22:00 사실 보고 문자 → 하은의 통화 가능 응답 → 통화 전환 → `당분간 각자 지내 보자고 했어.` → 침묵 뒤 내적 반응 → 하은 응답 순서를 SKIP 없이 확인했다.
- 저장 재개: 하은 응답 진행 중 페이지를 새로고침한 뒤 실제 `불러오기`를 눌렀다. 같은 Scene 시작의 사실 보고 문자부터 통화 가능 응답, 현재의 유리에 대한 설명과 `당분간 각자 지내 보자고 했어.`까지 동일한 순서로 복구됐다.
- 범위: 정확한 대사 오프셋 복원이 아니라 프로젝트가 채택한 Scene-start 복구 계약에 대한 PASS다.
- 결과: 브라우저 콘솔 error/warn 0, fixture 종료 후 테스트 전 사용자 저장 복원 PASS.
