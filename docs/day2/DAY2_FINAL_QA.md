## 서사 최종 확인

- 하은은 운동화·양말·운전·열쇠·사진·예비폰처럼 생활적인 세부로 먼저 관계의 온도를 만든다. 작은 열쇠 앞에서도 경직·회피·거짓말로 악역 코딩되지 않는다.
- 주인공은 관찰한 것, 하은의 주장, 아직 확인하지 못한 것을 분리하고 병원 기록·사진 뒷면·집의 흔적을 직접 대조한다. 한 물건만으로 진실을 단정하지 않는다.
- 담당 의사와 간호사는 귀가 가능과 회복 완료를 구분하고, 휴대폰 인계와 사고 기록 신청 경로를 분리해 말한다.
- 결혼·집 관리·차량 이동·관계 사진·열쇠·연락처 선택은 감정 버튼이 아니라 서로 다른 관계·조사 전략이며 즉시 대사와 저장 플래그로 회수된다.
- 병원 → 외부 → 차 → 집 문턱 → 가족사진 → 관계 사진 → 방 탐색 → 세 칸 기록 → 임시 연락처 → 혼자 남은 집의 감정 곡선이 유지된다.
- 원래 휴대폰은 병원 보관 중이고 임시 유심 예비폰은 연락 수단으로만 제공된다. 작은 열쇠는 끝까지 용도 미확인이다.
