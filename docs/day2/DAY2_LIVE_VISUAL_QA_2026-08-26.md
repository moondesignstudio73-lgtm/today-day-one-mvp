# DAY 2 실제 플레이 화면 품질 보정

상태: `LIVE PLAY QA COMPLETE / NEEDS FIX 0`

## 실제 화면에서 확인한 문제

- 방에서 컴퓨터를 조사하는 대사가 출력될 때 병실 배경과 DAY 1 하은 이미지가 함께 남았다.
- 원인은 저장 복원 시 현재 DAY 2 단계가 아니라 공통 병실 프레젠테이션으로 시작하고, 해당 세그먼트에 배경 전환이나 포즈 진입이 없으면 이전 화면이 계속 유지되는 구조였다.
- DAY 2 하은 포즈 7종은 높이 426~510px, 1인칭 동작 8종은 높이 335~470px라 전체 화면에서 68~107% 높이로 확대될 때 윤곽과 세부가 흐려졌다.
- 배경 7종과 전용 CG 4종은 1672×941이며 실제 화면에서도 선명했다. 이 파일들은 변경하지 않았다.

## 반영한 개선

- DAY 2 진행 단계별 복원 화면을 명시했다: 병실, 차량, 거실, 주인공 방과 단계별 하은 포즈를 저장 상태에서 재구성한다.
- 구버전 중간 체크포인트에서도 세션 프레젠테이션을 현재 DAY 2 단계로 다시 덮어써, 저장 당시 없던 화면 복원 필드에 의존하지 않도록 했다.
- 새 스토리 세션 시작 시 남아 있던 NPC 전·후면 레이어와 이벤트 CG를 숨겨 이전 컷의 잔상을 제거한다.
- 하은 저해상도 포즈 7종을 1200px 높이, 1인칭 동작 8종을 960px 높이의 `-hq-v2.png` 교정본으로 비파괴 생성했다.
- 투명 알파를 premultiplied 방식으로 리샘플링해 밝은 배경과 어두운 배경 모두에서 외곽 색 번짐을 줄이고, 원본 구도·색·캐릭터 외형·소품은 유지했다.
- 런타임은 교정본만 참조하고 기존 원본 파일은 재처리와 비교를 위해 그대로 보존한다.

## 검증

- `python scripts/process-day2-runtime-overlays.py`: 15종 생성 및 크기·비율·RGBA 알파 검사 PASS.

- `node tests/day2-runtime.test.mjs`: DAY 2 전체 런타임 계약 PASS.
- `node tests/day2-final-qa.test.mjs`: STORY/VISUAL/DIRECTION/AUDIO/GAMEPLAY/UX/BUG PASS.
- 로컬 실제 저장본 복원: DAY 2 연락처 선택 이후 화면이 `day2-home-entry` 배경과 `departing-open-wave-hq-v2` 포즈로 복원되고, 이전 NPC/CG 레이어가 숨겨지는 것을 확인했다.

## 이미지 처리 방식

기존 승인 이미지를 새로 그리지 않고 결정적 로컬 후처리를 사용했다. 생성형 이미지 편집은 캐릭터 얼굴·의상·소품의 불필요한 변화를 만들 수 있어 사용하지 않았다. 처리 규칙은 `scripts/process-day2-runtime-overlays.py`에 재현 가능하게 기록했다.
