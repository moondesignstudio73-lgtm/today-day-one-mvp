## 1. 장면·블로킹 계약

- 챕터: `m30-day2-homecoming`, 의료진이 귀가 조건을 충족했다고 판단한 날의 오전부터 늦은 오후. 플레이어 화면에는 `D-29`를 표시하지 않는다.
- 장소 흐름: 병실 → 회복 병동 복도 → 병원 로비·출입구 → 자동차 → 집 외관·현관·거실 → 주인공 방.
- 참여자: 1인칭 주인공, 이하은, 담당 의사, 간호사.
- 극적 목적: 주인공이 몸의 안전 기준, 하은과의 접촉 범위, 집 출입 권한, 물건 조사 순서를 직접 정하는 모습을 행동으로 읽히게 한다.
- 이전 선택 콜백: DAY 1의 `contact_boundary`, `contact_acceptance`, `identity_first`는 Scene 02의 지원 방식에, `family_question_first`, `accident_interest`, `recovery_focus`는 의료진·서류·사진을 다루는 동작에 반영한다.
- 금지 정보: 사고 원인·동승 여부·하은의 정체·잠금 프로필을 몸짓으로 암시하지 않는다. 작은 열쇠는 미분류 물건이며 하은은 숨기거나 빼앗거나 굳지 않는다.
- 감정 곡선: 결혼 대화의 긴장 → 몸의 한계와 협력 → 절차적 귀가 → 바깥세상 과부하 → 생활적 동행 → 자기 집의 낯섦 → 직접 조사 → 안전한 중단과 다음 목표.
- 후속 훅: 하은이 떠난 뒤 주인공이 `확인 / 주장 / 미확인`을 직접 기록한다.

## 2. 공통 블로킹 원칙

- 하은의 다정함은 선점이나 신체 접촉이 아니라 묻기, 열린 손 보이기, 길을 비키기, 물건을 주인공 쪽으로 돌려놓기로 표현한다.
- 하은은 출입문을 막거나, 물건을 등 뒤에 숨기거나, 주인공의 서랍·컴퓨터·휴대폰을 먼저 만지지 않는다.
- 주인공은 1인칭 시점을 유지한다. 몸의 상태와 판단은 손, 난간, 열쇠, 사진, 메모, 임시 예비폰 레이어로 보여 주며 상시 얼굴 스프라이트를 만들지 않는다.
- 운전 중 하은의 두 손과 시선은 도로 안전을 우선한다. 대화할 때 정면을 오래 보거나 핸들에서 양손을 떼는 포즈를 쓰지 않는다.
- 의료진은 환자 동선을 열어 두고 절차를 설명한다. 하은은 의료진을 대신하거나 뒤에서 기록을 훔쳐보지 않는다.
- 같은 대화 안에서 손 제스처를 반복하지 않는다. 목적·접촉 권한·상호작용 소품·공간 주도권이 바뀔 때만 포즈를 전환한다.
- 걷기, 일어서기, 자동차 승하차, 문 열기에는 `준비 → 수행 → 안정 또는 중단`의 연속 동작이 필요하다. 정지 포즈 한 장으로 안전 판단을 생략하지 않는다.

## 8. 화면 배치·레이어·안전 규칙

- 기본 레이어 순서: `배경 → 비화자 몸 → 화자 몸 → 교체형 팔·손 → 상호작용 소품 → 얼굴/입 → 환경 전경 → UI`.
- 복도에서는 난간과 하은 손이 겹치지 않게 하며, 주인공 팔을 받치는지 여백을 두는지가 중앙 9:16 크롭에서도 보여야 한다.
- 자동차는 `배경·창밖 패럴랙스 → 하은 몸 → 양손·핸들 → 표정 → 전경 대시보드 → UI` 순서다. 안전벨트, 좌측 운전석, 도로 주시가 가려지면 불합격이다.
- 집 열쇠와 작은 열쇠는 크기·고리·색을 달리한다. 큰 열쇠는 현관 출입용, 작은 열쇠는 용도 미확정으로만 보이게 한다.
- 원래 휴대폰은 DAY 2에 등장시키지 않는다. 임시 예비폰은 낡은 외형과 단순한 초기 화면으로 구분하며 잠금 프로필·메시지·과거 사진을 표시하지 않는다.
- 가족·커플사진의 얼굴과 뒷면 정보는 PHASE 15 CG/컷인 계약을 따른다. 하은 손이 사진 일부를 가려 비밀을 숨기는 구도를 만들지 않는다.
- 하단 28% UI 및 좌우 12% 크롭에서 손, 허락 거리, 열쇠 종류, 사진 방향, 연락처 입력이 읽혀야 한다.
