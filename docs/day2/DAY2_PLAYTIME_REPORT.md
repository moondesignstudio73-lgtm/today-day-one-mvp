# DAY 2 일반 읽기 속도 플레이타임 측정

측정일: 2026-08-25  
대상: 잠금된 DAY 2 실제 런타임의 대표 관계 경로와 방 탐색 전 순서  
판정: **PASS — 대표 경로 13.84~14.31분**

## 측정 방식

`scripts/measure-day2-playtime.mjs`가 실제 `src/day2-campaign-runtime.mjs`의 재개 가능 구간을 선택 순서대로 조립해 다음 시간을 합산한다.

- 한국어 보통 읽기 속도: 분당 340자
- 대사·내레이션: 글자 수 기반 읽기 시간 + 줄 전환 인지 0.5초, 최소 체류 1.4초
- 런타임 고정 연출: Scene 전환 1.08초, CG의 실제 `duration`, 캐릭터 입장 0.42초, 소품·SFX·BGM 자동 큐의 실제 대기값
- 선택 숙고: 선택 시점당 5초
- SKIP·AUTO 미사용, 타이핑 시간은 읽기와 동시에 진행되어 별도 중복 합산하지 않음

DAY 2는 병원 퇴원부터 집 탐색과 혼자 남는 결말까지 12개 Scene을 가진 중요 챕터다. 잠금본의 승인된 깊이를 유지하면서 느림·보통·빠른 읽기 모두 12~17분 품질 범위에 들어오는지를 판정했다.

## 방 탐색 전 순서

- 5개 대상 중 3개를 고르는 60개 순열을 구성했다.
- 작은 열쇠가 포함된 순열에는 처리 전략 2종을 각각 적용해 총 96개 탐색 경로를 계측했다.
- 보통 읽기 범위는 14.15~14.44분이었다.
- 모든 경로에서 선택한 일반 탐색 결과 대사와 작은 열쇠의 `미확인` 판정이 실제 시퀀스에 존재함을 검사했다.
- 계측 중 작은 열쇠를 먼저 찾은 경로에서 마지막 일반 탐색 반응이 누락될 수 있던 런타임 결함을 발견해, 각 탐색 결과가 선택 직후 한 번만 재생되도록 수정했다.

## 밀도·서사 판정

- 12개 Scene, 8~9개 선택, 157~159개 텍스트 스텝이 병원 퇴원·이동·집 문턱·사진·방 탐색·연락 수단·혼자 남은 결말의 서로 다른 극적 기능을 담당한다.
- 관계 대화와 조사 행동이 번갈아 진행되어 약 30~90초마다 장소·목표·정보·감정·상호작용이 변한다.
- 하은의 생활적 온기와 주인공의 확인 중심 사고를 반복 문장이나 인위적인 Pause로 늘리지 않았다.
- 열쇠 유무와 선택 순서에 따른 시간 편차가 0.29분으로 작고, 어느 탐색 순서도 반응 손실이나 비정상적인 길이 차이를 만들지 않는다.
- 승인된 잠금 시나리오를 줄이거나 확장할 필요가 없으며 PHASE 23 최종 7영역 QA로 이관한다.
