## 3. 선택·탐색 QA

- 결혼 선택은 `연기 / 관계 이유 조사 / 현재 호감 표현`으로 전략이 다르다.
- 집 대응은 `감사 / 관리 범위 검증 / 죽음 가능성 질문`으로 관계 비용과 얻는 정보가 다르다.
- 차 안 선택은 `공포 인정 / 과거 습관 질문 / 기록 경로 확인`으로 기능이 다르며 마지막 전략은 `accident_interest`에서만 열린다.
- 관계 사진 선택은 사진을 현재 감정의 증명으로 과대 해석하지 않는다.
- 방 탐색 다섯 개는 일상 정보, 추후 디지털 조사, 관계 생활감, 외부 인물 연결, 미분류 물건으로 결과 역할이 겹치지 않는다.
- 작은 열쇠는 용도를 확정하지 않고 하은도 모른다고 답한다. 조기 범인 코딩이 없다.
- 연락처 선택은 관계 온도만 바꾸며 원래 휴대폰의 기록 접근권을 대신하지 않는다.
- 선택 직전·직후 Scene, 플래그, 탐색 횟수, 다음 스텝을 함께 저장하는 계약이 명시돼 있다.

## 4. 캐릭터·지식 QA

### 주인공 — PASS

- 증상 기준을 확인하고 무리한 독립 보행을 성공담으로 만들지 않는다.
- 사진, 열쇠, 하은의 말을 `확인 / 주장 / 미확인`으로 분리한다.
- 하은을 무조건 믿지도 한 물건으로 범인 취급하지도 않는다.

### 이하은 — PASS

- 생활 농담과 실용적인 준비가 먼저 보인다.
- 접촉, 집 진입, 방 진입 전에 선택권을 돌려준다.
- 모르는 사진 장소·열쇠 용도를 아는 척하지 않는다.
- 비밀 전화, 얼어붙은 표정, 빠른 거짓말, `아무것도 아니야`로 반전을 광고하지 않는다.

### 의료진 — PASS

- 기억 회복을 보장하지 않고 귀가·중단 기준을 구분한다.
- 사고 경위 기록을 의료 기록과 분리한다.

## 5. 정보 공개·복선 QA

- 가족사진은 부모의 존재를 재확인하지만 새 사고 사실을 공개하지 않는다.
- 두 사람의 사진은 과거 관계의 증거 후보일 뿐 현재 사랑의 확정 증거가 아니다.
- 집 열쇠는 접근권을 뒷받침하지만 하은에게 맡긴 경위는 주장 상태다.
- 작은 열쇠는 기존 전체 설정과 연결되기 전까지 `미분류 물건`이다.
- 원래 휴대폰은 병원 보관 중이며 임시 예비폰과 분리된다. 기존 DAY 3 인계 계약과 충돌하지 않는다.
- 하은의 MBTI·직업·상세 프로필, 사고 원인, 가해자, 동승 여부, 후반 반전은 노출되지 않는다.

## 6. 시간축 처리

DAY 1 직후 1년 혼수 환자가 다음 날 곧바로 영구 퇴원하는 것으로 확정하면 의료 개연성이 약해진다. 승인된 수정본은 정확한 경과 일수와 `D-29` 표시를 플레이어 대사에서 제외하고, `의료진이 귀가 조건을 충족했다고 판단한 날`로만 표현한다. 사용자가 이 보류 조건이 포함된 수정본을 승인했으므로 SCENARIO LOCK은 아래 구현 제약을 가진다.

- 전역 DAY/D-DAY 시간축이 확정되기 전에는 DAY 2 종료 화면에 `D-29`를 표시하지 않는다.
- 구현 시 퇴원 시점을 `다음 날`이라고 추가 확정하지 않는다.
- 전역 시간축 결정은 Scene 핵심 구조를 바꾸지 않는 별도 시스템 결정으로 남긴다.
