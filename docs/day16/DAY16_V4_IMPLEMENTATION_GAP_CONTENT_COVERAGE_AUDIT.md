# DAY 16 V4 구현 격차·콘텐츠 커버리지 감사

권위·분기 계약: `docs/day16/DAY16_NOTION_SOURCE_LOCK_V4.md`

상태: `GAME ENTRY + ACTUAL BROWSER QA PASS · ONE SOURCE VARIANT UI-LOCKED`

이 문서는 구현 핸드오프나 대본 사본이 아니다. 현재 V1과 정본 V4 사이의 교체 범위, 재사용 가능한 실제 표면, 다음 계약이 반드시 답해야 할 질문을 잠그는 감사 결과다. 정확 대사·선택 버튼·반응·장면별 진입/합류점은 최신 Notion 하위 본문과 이후 정확 원문 레지스트리에서만 가져온다.

## 결론

기존 V1은 최신 Notion V4와 직접 대응하는 장면이 `0/24`였고, 지훈 한 명의 현재 소개·연락 범위·만남 종료권·제3자 공유를 다루는 8장면·3선택 챕터였다. 현재 신규 V4 계층에는 24장면·12선택의 exact registry, 상태·지식·레거시 계약, 분기 resolver, 선택·체크포인트 runtime, 안전한 장면 봉투, 선택별 정확 반응, 선택 직후 연속 출력, 경로별 player-facing step 투영, SCENE 10 현재 대화의 exact-note 변형, 몰입형 어댑터, 게임 브리지와 실제 `game.js` 진입이 있다. 카페·집 경로의 실제 브라우저 완주도 통과했다.

- SCENE 10 현재 대화 경로는 구현 메모의 두 대사를 전용 불변 변형으로 정본화했다. 과거 대화 preamble이나 새 연결 문장을 재사용하지 않는다.
- 선택 6의 끝난 관계 첫 옵션: 버튼 대체는 명시됐지만 유리의 완전한 선택 반응 블록이 없다. 사용자 승인에 따라 이 한 옵션만 게임 표면에서 숨기고 직접 선택도 거부한다. `연인의 이름` 반응을 허위 재사용하거나 레지스트리에서 소스 공백을 지우지 않는다.

신규 진행은 V4로 교체하고, 기존 `m30-day16-current-social-circle`과 `day16CurrentSocialCircle*`는 이미 진입·완료한 V1 저장 복원 전용으로 유지한다.

## 재사용 가능한 실제 게임 표면

| 표면 | 통합 방식 | 분류 |
|---|---|---|
| `카페 모퉁이`와 카페 배경 | 지훈 동석/혼자 방문, 유리 우연 재회, 빈 컵·책·메뉴·좌석 행동 | 필수 |
| 주인공의 방 | 아침 시간·하은 연락, 집 휴식 경로, 사진 폴더, 저녁 연락, 종결 | 필수 |
| 메시지/연락 상태 | 지훈의 시간 제안, 하은 연락휴식, 유리 연락 동의와 모레 제안, 마지막 하은 고지 | 필수 |
| 유리 NPC/heroine 데이터 | 28세 고서 복원가·전 여자친구 프로필만 재사용, V4 대사와 상태는 신규 | 필수 |
| DAY 15 V4 상태 | 실제 참석/자기 오후와 하은 연락·경계 결과만 콜백 | 조건부 |
| 사진 폴더/현재 사진 | 집 경로에서 이름을 추정하지 않고 한 장 표시·현재 사진 분리·다른 일 선택 | 집 경로 필수 |

빈 장소 방문, 복원 직업 설명, 연애 판정 UI, 사고 추리 장면을 추가하지 않는다. 각 표면은 원고의 행동·관계·지식 출처·후속 중 하나를 실제 상태로 남겨야 한다.

기존 공용 `situation-ex-girlfriend-reunion`은 카페 50% 발동과 유리의 유혹·호감도 상승을 전제로 해 V4의 확정 DAY 16 재회, 신규 로맨스 금지, 선택별 연락 동의와 충돌한다. V4 진행 중에는 이 공용 이벤트가 선행·중복·대체 발동하지 않도록 격리하고, V4 선택을 공용 유혹 수락으로 변환하지 않는다. 유리 프로필의 이름·나이·직업만 재사용한다.

## 상태·호환 전략

- 신규 필드는 `day16V4*` 네임스페이스로 분리했고 V1의 3전략에서 V4 선택을 추정하지 않는다. 타입·기본값·enum·체크포인트·쓰기 권한과 선택 이력 prefix는 실행 상태 계약이 소유한다.
- V4 미진입·진행·완료, V1 진행/완료, 버전 없는 모순 저장은 fail-closed 진리표로 분리됐다. V1 진행·완료 저장은 V1로 그대로 복원하고 V4로 추정 이주하지 않는다. V4는 신규 DAY 16 진입에만 선택된다.
- 선택 1이 외출 지훈 동석/외출 혼자/집을 배타적으로 정한다. `외출 혼자`도 카페에서 유리를 만나며, `집`만 유리 대면·지식·연락·초대를 생성하지 않는다.
- 하은 아침 연락 유지/자기 시간 고지/연락휴식은 DAY 15 실제 관계·연락 상태와 모순되지 않아야 한다.
- 유리 대면, 대화 수락, 과거 대화 깊이, 현재 관계 공개, 연락 교환, 모레 제안/응답은 독립 상태다.
- 지훈 동석 지식은 실제 동석 경로에서만 생긴다. 혼자 카페와 집 경로에서 지훈 현장 대사를 만들지 않는다.
- 하은 저녁 공개는 `유리 만남 사실`, `정리 뒤 말하기`, `의도적 축약/비공개`를 구분하고 하은 지식 장부를 그 선택보다 앞서 갱신하지 않는다.
- DAY 17/18 인접 계약은 유리 약속을 `제안됨`, `수락 의향`, `거절`, `내일 답`, `없음`으로 분리하며 자동 식사 약속을 만들지 않는다.
