## QA에서 발견하고 수정한 결함

1. 공통 종료 문단이 세 만남 전략 중 어떤 것을 골라도 45분 타이머를 전제로 해 `social16_meeting_public_45`의 고유 비용과 기억을 다른 두 선택에 덮어씌웠다. 45분 종료, 현재 질문 완료 종료, 설명 없는 즉시 종료의 세 실행 결과를 조건부 행동으로 분리했다.
2. 아홉 개 선택 제목이 기존 런타임의 플레이어 표시 문구와 의미는 같지만 문장이 달라 후속 구현 시 잠금본과 UI가 어긋날 수 있었다. `DAY16_CONTACT_CHOICES`, `DAY16_MEETING_CHOICES`, `DAY16_SHARING_CHOICES`의 표시 문구와 정확히 일치시켰다.
3. 휴대전화와 관계망에 관한 두 내레이션이 `연출`, `접근 경로`처럼 작가의 의도를 직접 설명했다. 화면을 밀거나 가리지 않는 손동작, 빈 명단 칸, 닫힌 초대 화면처럼 플레이어가 볼 수 있는 사실로 교체했다.
4. 계약과 대본이 PASS 초안 상태에 머물러 후속 에셋·런타임 관문이 참조할 잠금 기준이 없었다. 정적 검사 통과 뒤 각각 `CHAPTER CONTRACT LOCK V1`, `NARRATIVE QA PASS · SCENARIO LOCK V1`으로 승격했다.

## 캐논·지식 장부 감사

1. 주인공은 과거 절친이라는 사실과 현재 연락 권한을 분리한다.
2. 지훈의 현재 이름·나이·직업·번호·공개 작업은 서로 대조되지만 이것을 사고 진실의 증명으로 확대하지 않는다.
3. 사고 관련 직접 지식은 사고 이틀 전 통화와 통화 기록까지이며 정확한 문장·사고 당일 경위는 미확인이다.
4. 다른 친구망은 독립 출처가 있을 가능성만 열고 명단·초대 링크·미디어를 자동 해금하지 않는다.
5. 하은은 DAY 4 상세 대화를 알지 못하며 답장·관계·공유 결정을 대신하지 않는다.
6. 고의 사고, 가해자, 차량 조작, 가짜 하은 진실, 하은 잠금 프로필은 공개하지 않는다.

## 화자·관계 감사

- 하은은 토스트 굽기, 답장 문장, 커피 주문, 귀가 식사, 알람 시간처럼 생활 소재로 대화를 연다. 지훈을 질투의 대상으로 만들거나 주인공의 관계를 보증·통제하지 않는다.
- 주인공은 신원→현재 역할→연락 목적→출처→권한→행동 검증 순서로 좁힌다. 한 번의 약속 준수를 전체 신뢰나 사고 판단으로 확대하지 않는다.
- 지훈은 편집·자막·러닝타임 농담 뒤 검증 가능한 자료나 행동 약속을 붙인다. 과거 별명, 포옹, 추억 퀴즈, 단체방을 친밀도 시험으로 사용하지 않는다.
- 이름표를 가려도 하은의 생활적 확장, 주인공의 짧은 조건 확인, 지훈의 편집 비유와 자기 제한이 구분된다.
- 하은 관계 변화는 계약이 허용한 소폭 상승만 가능하며 대본에 없는 암묵적 수치 변화는 없다. 윤서진 `seojinAffection`과 `seojinStatusInterest`는 각각 독립 값·변화 0이다.

## 선택 전략 감사

### 선택 1 — 현재 연락 범위

- `social16_contact_one_to_one`: 빠른 개인 연락을 열되 제3자 소개는 재질문한다.
- `social16_contact_written_intro`: 현재 소개를 글로 남겨 검증성을 높이는 대신 관계 온도는 천천히 오른다.
- `social16_contact_no_group`: 개인 연락과 집단 접근을 명시적으로 분리한다.

### 선택 2 — 다음 만남의 경계

- `social16_meeting_public_45`: 공개 장소와 45분 종료 시각으로 예측 가능성을 확보한다.
- `social16_meeting_topics_current`: 현재 질문이 끝나는 순간 대화를 닫아 과거 자료의 자동 진입을 막는다.
- `social16_meeting_exit_anytime`: 이유를 설명하지 않고 즉시 끝낼 권리와 재연락 여부를 분리한다.

세 전략은 QA 수정 뒤 실제 종료 행동도 타이머·질문 목록·직접 선언으로 구분된다.

### 선택 3 — 내 소식의 공유 범위

- `social16_sharing_current_notes`: 직접 확인한 현재 정보만 관계망 장부에 남긴다.
- `social16_sharing_old_media_closed`: 과거 미디어의 존재와 열람 권한을 분리한다.
- `social16_sharing_ask_each_person`: 제3자 상태 공유를 사람별 사전 동의로 고정한다.

## 플레이 밀도·감정 곡선 감사

- 식탁의 연락처 분류와 토스트 농담으로 조심스러움과 생활 온기를 동시에 연다.
- 답장 작성은 하은이 문장을 제안하되 주인공이 시간·장소·채널을 확정하는 공동 행동이다.
- 카페 입구·주문·좌석·명함·작업 화면·알림·타이머·질문 목록·출구가 대화의 조건을 실제로 바꾼다.
- 사고 증언 뒤 즉시 출처 평가→추가 질문→명단 보류→현재 행동 판단의 반응 시간을 둔다.
- 귀가 후 식사와 관계망 메모로 긴장을 낮추고 DAY 17의 처방·병원·약국 기록 확인이라는 구체적 목적을 남긴다.
- 반복 설명, 장식 독백, 긴 Pause, 동의어 선택, 공포 연출로 플레이타임을 채우지 않는다.
