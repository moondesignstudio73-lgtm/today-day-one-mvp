## 원본과 구현

SCENE 11의 원본 순서는 식당 밖 이동 → 유리가 자기 겉옷을 여밈 → 주인공은 대신 여며 주지 않음 → 작별이다. 유리가 야외에서 기본 블라우스 차림으로 돌아가던 연속성 오류를 없애기 위해, 투명 재킷 스프라이트와 `yuri-outerwear-close` 비언어 cue를 연결했다. 행동 문장은 일반 대화·독백으로 출력하지 않는다.

새 자산:

- `assets/heroines/yuri/yuri-ex-girlfriend-jacket-2d-v1.png`
- 1024×1536, PNG color type 6(RGBA), 모서리 alpha 0
- 기존 유리의 얼굴·머리·자세·책·손·치마를 유지하고 닫힌 차콜 재킷만 추가
- 손은 기존 2D 애니메이션 셀 채색을 유지하며 실사 피부 질감이 없음

## 생성·반려 기록

built-in imagegen의 identity-preserve 편집을 사용했다. 첫 결과는 체크무늬를 실제 24-bit RGB 픽셀로 그려 넣어 반려했고 프로젝트에 복사하지 않았다. 그 결과를 background-extraction으로 한 번만 수정한 두 번째 결과는 실제 RGBA와 투명 모서리를 확인한 뒤 버전 파일로 저장했다.

최종 편집 요구의 핵심은 다음과 같다.

> 기존 성인 유리의 얼굴, 머리, 표정, 전신 자세, 책, 양손, 치마, 스타킹과 구두를 그대로 보존하고 닫힌 차콜 재킷만 추가한다. 배경은 실제 alpha 0이며 체크무늬·매트·광륜이 없어야 한다. 손은 2D 애니메이션 셀 채색을 유지하고 실사 피부·사진 조명·혼합 화풍을 금지한다.
