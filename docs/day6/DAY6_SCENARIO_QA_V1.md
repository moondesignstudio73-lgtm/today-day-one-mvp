# DAY 6 시나리오 자체 QA V1

검수 대상: `docs/day6/DAY6_SCENARIO_DRAFT_V1.md`  
검수 방식: 챕터 계약, 8개 Scene, 3×3×3 선택 경로, DAY 5 콜백, 지식 장부, 미스터리 공개 예산, 저장 복원 계약을 대조한다.

## 판정

- `PASS — 구조`: 8개 Scene이 아침 역할 협상 → 동선 확인 → 약국 → 장보기 → 취향 확인 → 회사 경계 콜백 → 데이트 계획 → 생활 지도 완성으로 진행한다.
- `PASS — 플레이 밀도`: 주소판, 신호, 처방, QR, 가격표, 결제, 메뉴 시음, 메시지, 달력, 지도 기록을 실제 행동으로 다룬다. 중요한 변화를 요약이나 시간 건너뛰기로 대체하지 않는다.
- `PASS — 선택 전략`: 경로·장보기·데이트의 세 선택은 각각 안전/협업/자율성, 경제/공동 기준/역할 분담, 새 장소/조건부 재방문/교대 선택이라는 다른 행동 전략이다.
- `PASS — 전 경로 합류`: 27개 조합 모두 약국·현재 취향·업무 경계·DAY 7 계획을 확보하며, 특정 선택만 정답으로 취급하지 않는다.
- `PASS — DAY 5 연속성`: 최종 복귀 전략 3종이 서로 다른 발신자·자료 형식으로 콜백된다. 회사 메시지는 휴식일에 새 업무를 부과하지 않는다.
- `PASS — 서진 양축`: `AFFECTION`과 `STATUS_INTEREST`의 기존 우위는 메시지 온도에만 반영하며 DAY 6에서 두 수치를 자동 상승시키지 않는다.
- `PASS — 하은 Voice`: 먼저 말하고 장난·생활 정보를 제공하지만 주인공의 길·취향·저장·데이트 결정을 대신하지 않는다. 초반 악역 코딩이 없다.
- `PASS — 주인공 지능`: 주소판·신호·유통기한·결제 계정·회신 기한을 확인하고 관찰→가능성→확인→판단→행동 순서를 유지한다.
- `PASS — 정보 예산`: 원래 폰/임시 예비폰을 구분하고 생활 영역만 확장한다. 사고 고의성, 가짜 하은, 진짜 하은, 잠금 프로필은 노출하지 않는다.
- `PASS — 무해한 차이`: 카페 취향 차이는 장소·시점에 따라 함께 참일 수 있으며 단서나 거짓말로 연출하지 않는다.
- `PASS — 저장 복원`: 7개 복원 지점과 3개 전략 플래그, 생활 기록, 해금, DAY 7 후속 훅이 명시돼 있다.
- `PASS — 플레이타임`: 8개 장소·활동 전환과 세 선택·후속 반응으로 10~14분을 목표로 하며 반복 대사나 긴 Pause로 분량을 채우지 않는다.

## Voice Blind Check

- 하은: 생활 소재로 먼저 말을 열고 구체적 장난 뒤 선택권을 돌려준다.
- 주인공: 문장이 짧고 확인 기준을 말하며 감정을 행동과 일정으로 표현한다.
- 서진: 메시지에도 목적·기한·업무 경계가 있고 축 우위에 따라 건조한 평가와 개인적 온도를 구분한다.
- 민호: 직접 경험과 전달 정보의 선을 문서 형식에서도 유지한다.
- 팀장: 권한·시간·중단 기준을 짧은 문장으로 확정한다.

## MUST / MAY / MUST NOT 점검

- `MUST REVEAL`: 임시 예비폰, 생활 반경, 적응 방문 상태, 현재형 데이트 — `PASS`
- `MAY REVEAL`: 과거 카페 방문과 장소별 취향 차이 — `PASS`, 무해한 해석 보존
- `MUST NOT REVEAL`: 사고 배후, 하은 정체, 잠금 프로필, 동승 확정 — `PASS`
