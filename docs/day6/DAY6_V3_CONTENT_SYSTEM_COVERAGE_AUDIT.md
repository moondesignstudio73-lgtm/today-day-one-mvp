# DAY 6 V3 콘텐츠·장소·시스템 커버리지 감사

검수 기준: Notion `DAY 6 — 처음 가는 길 | SCENARIO V3` 하위 페이지 본문, DAY 2~3 품질 기준, Narrative Director, Chapter Story Writer.

## 결론

현행 DAY 6은 `우리가 사는 동네` V1이며 4개 런타임 세그먼트, 선택 3개, 약국·마트·동네 카페·공원과 저녁 자유행동으로 구성돼 있다. 최신 사용자 승인 V3는 `처음 가는 길`의 SCENE 01~23, 선택 11개, 카페 모퉁이·김밥마을·오후의 레코드·기억의 공원에서 과거 데이트 재현을 포기하고 현재형 첫 데이트를 만드는 이야기다. 단순 보강으로는 누락 0을 달성할 수 없으므로 V3 데이터층을 새로 구성하되 기존 저장 키와 V1 완료 저장은 호환 이행층으로 보존한다.

## 실제 지도·프리모드 통합

- `small-cafe` 카페 모퉁이: 과거 메뉴·자리·사진 재현이 하은의 서운함으로 전환되는 필수 사건.
- `gimbap-village` 김밥마을: 현재 취향을 실제 주문·실패·나눔으로 확인하는 필수 사건.
- `vinyl-store` 오후의 레코드: 둘 다 처음인 장소에서 음악 선택과 메모 카드가 생기는 필수 사건.
- `memory-park` 기억의 공원: 현재 사진·카드·동의 기반 손 선택과 하루 이름을 회수하는 필수 사건.
- 동수역·연희역: 별도 방문 과제가 아니라 길 찾기 실패와 공동 지도 확인을 만드는 이동 사건.
- 기존 약국·마트는 V3 본편에 억지로 삽입하지 않는다. 기존 V1 저장의 해금·플래그는 마이그레이션 호환용으로만 보존하고, 이후 선택/반복 콘텐츠 커버리지 표에 남긴다.
- 저녁 자유행동은 본편을 반복하지 않고 새 앨범·메모 카드·DAY 7 후보를 정리하는 후속 반응으로 조정한다.

## 상태·저장 호환 계약

- 기존 `day6RuntimeStage`, `day6RouteStrategy`, `day6ErrandStrategy`, `day6DatePlan`과 관련 해금은 삭제·이름 변경하지 않는다.
- 신규 V3는 별도 버전 플래그, 장면 체크포인트, 11개 정규 선택 키, 카페 사진 여부, 현재 사진 경로, 손 시도/질문/기다림, 실제 손잡기 성립, 하루 이름, 관계별 작별·문자 분기를 저장한다.
- V1 완료 저장은 DAY 6을 재강제하지 않고 기존 DAY 7 도달성을 유지한다. V3 신규 플레이만 23장면 계약을 사용한다.
- 모든 선택 효과는 즉시 반응과 후속 장면 콜백을 함께 가지며, 불러오기 후 중복 적용하지 않는다.
- 윤서진 `AFFECTION`과 `STATUS_INTEREST`는 DAY 6에서 자동 변경하지 않는다.

## 내러티브 관문

- 하은의 주체성: 과거를 설명하는 안내자가 아니라 서운함과 현재의 호기심을 말하고 계획표를 접는 공동 주체 — PASS 설계.
- 주인공 사고 흐름: 사진 관찰 → 과거 재현 가능성 → 음료·자리·질문으로 확인 → 하은 반응 판단 → 계획 포기와 현재 행동 — PASS 설계.
- 정보 예산: 기억 회복 0, 현재형 관계 진전 1, 윤서진 사진 알림 1, 사진 내용 공개 0 — PASS.
- 스킨십: LOW/경계 경로 비성립 무벌점, MID 이상 상호 반응, 기다림 선택 자동 접촉 금지 — PASS 설계.
- DAY 7 훅: 서점/저녁 등 후보와 윤서진 알림만 남기며 경로·사진 정답 미확정 — PASS.
