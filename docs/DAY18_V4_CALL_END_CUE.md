# DAY18 SCENE18 통화 침묵·종료 — 2026-09-04

## 구현 전 계약과 계획

원문 SCENE18의 침묵, “듣고 있어.” 뒤 민망함, “내가 지금 널 이해하는 말을 해 주기는 어려워.” 뒤 종료를 연결한다. 새 장면/선택/상태 스키마는 추가하지 않는다.

입력: 기존 검증된 chapter의 relationship_future 및 future_others 선택. 출력: 저장 사실 변경 없음. 통화 불가/문자 연기/무연락 경로에는 종료 사건을 만들지 않는다.

장면 그래프: 통화 수락 → 기존 보고 → 말 없는 통화 화면(입력 잠금) → “듣고 있어.” → 침묵을 고장처럼 여긴 민망함 → 관계 선택. 다른 만남 선택은 마지막 하은 발언 → 통화 종료 표시(입력 잠금) → 원문 독백 → 여행 후보로 합류한다.

기존 대화 패널을 사용하며 상태 표시는 대사/LOG에 기록하지 않는다. 화면 확인·손 바꾸기는 물리 연출이 없으므로 완료로 세지 않는다. 기존 storyPause의 입력 잠금/타이머 정리 방식을 사용한다. 저장 재개는 기존 선택 반응 재생 원칙을 유지한다.

검증 계획: 실제 엔진 핸들러의 대사 비출력·패널 상태·입력 잠금 예약 검사, 세 관계 선택 및 통화 불가 반례, 브라우저 침묵→응답/종료→독백/저장 재개. DAY18 PARTIAL 유지.
