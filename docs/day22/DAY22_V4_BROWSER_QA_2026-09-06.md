- DAY22 bridge를 `v=2`, 최상위 game script를 `v=258`로 올려 배포 캐시 사슬 갱신

fixture에 `Neutral · 부산 별실`, `Mixed · 서울 당일`을 추가했다. 두 상태 모두 DAY18→21 production 이력을 실제 reducer/bridge로 완주해 만들며, 부산 별실은 DAY21의 `separate_spaces`, 서울 당일은 `seoul` 선택 결과를 그대로 DAY22 입력으로 사용한다.

### 플레이 중 발견한 HIGH 텍스트 오류

원문에 포함된 분기 설명이 `monologue`로 전달되어 다음과 같은 문장이 일반 대화창에 노출됐다.

- `각자 공간을 선택한 여행에서는 ... 장면이 생기지 않았다.`
- `하은과 만났다면 ... 농담할 수 있었다.`
- `서울 당일이면 자기 집에서 먹을 수도 있었다.`

해당 조건은 런타임에서 이미 확정되므로 화면에는 선택된 경로의 실제 사실만 나오도록 source-grounded projection으로 교체했다. 별실에서는 `각자 씻고 편한 옷을 입었다.`와 실제 통화 문장만, 서울에서는 `가방은 가벼웠다.`, 가까운 식당·카페·귀가 사실만 출력한다. 원문 참조는 유지하고 배제 조건은 내부 stageAction 또는 상태 계약에 남겼다.

부산 별실과 서울 당일 데스크톱은 PASS다. DAY22 전체는 미여행·거절 경로와 모바일 의미 경로가 남아 **PARTIAL**이다. 다음 시작점은 연락 불가 미여행과 연락 가능 미여행 데스크톱 비-SKIP QA다.
