## 발견한 HIGH 오류와 수정

첫 실행은 DAY22 첫 선택 직후 `DAY22_BACKGROUND_MISSING:day22-busan-station`으로 안전 종료됐다. manifest 원본에는 배경이 있었지만 `game.js`와 DAY22 bridge가 서로 다른 캐시 세대의 asset manifest를 읽어 브라우저에서만 누락된 문제였다.

- `game.js`와 `day22-v4-game-bridge.mjs`가 동일한 `asset-manifest.mjs?v=24`를 사용하도록 고정
- DAY22 bridge를 `v=2`, 최상위 game script를 `v=258`로 올려 배포 캐시 사슬 갱신
- bridge 정적 회귀에 양쪽 manifest 버전 일치 검사를 추가

수정 후 같은 fixture를 처음부터 다시 실행했고 부산역 배경 누락과 안전 종료가 재발하지 않았다.

Friendly·부산·공유 숙소 데스크톱 의미 경로는 PASS다. 다만 Neutral/Distant/Mixed, 부산 별실, 서울 당일, 미여행, 389×844 모바일 경로는 아직 실제 브라우저 검증 전이므로 DAY22 전체 상태는 **PARTIAL**을 유지한다.

## 부산 별실 · 서울 당일 후속 — 2026-09-06

fixture에 `Neutral · 부산 별실`, `Mixed · 서울 당일`을 추가했다. 두 상태 모두 DAY18→21 production 이력을 실제 reducer/bridge로 완주해 만들며, 부산 별실은 DAY21의 `separate_spaces`, 서울 당일은 `seoul` 선택 결과를 그대로 DAY22 입력으로 사용한다.

### 부산 별실

- 실제 화면 선택으로 SCENE01부터 DAY23까지 SKIP 없이 완주
- 별실 도착 뒤 하은의 편한 차림·침대 동석·얼굴 칭찬·포옹·손잡기 비노출
- C14는 `나는 지금 이대로 쉬고 싶어.` 하나만 노출
- 각자 준비 후 짧은 통화와 자기 방 인사로 종료
- 공동 사진 중단 경로에서 보관 resolution을 만들지 않음

### 서울 당일

- 가까운 이동·식당·산책·카페·귀가로 SCENE01~22/C1~17을 거쳐 DAY23까지 SKIP 없이 완주
- 부산역·밀면·해운대·숙소·숙박 결제·현재 물리 접촉 비노출
- 공동 사진 중단 뒤 삭제된 사진을 귀가 장면에서 복원하지 않음
- C16 직전 새로고침→타이틀 `이어하기`→같은 밤 식사 선택 복구 PASS

### 플레이 중 발견한 HIGH 텍스트 오류

원문에 포함된 분기 설명이 `monologue`로 전달되어 다음과 같은 문장이 일반 대화창에 노출됐다.

- `각자 공간을 선택한 여행에서는 ... 장면이 생기지 않았다.`
- `하은과 만났다면 ... 농담할 수 있었다.`
- `서울 당일이면 자기 집에서 먹을 수도 있었다.`

해당 조건은 런타임에서 이미 확정되므로 화면에는 선택된 경로의 실제 사실만 나오도록 source-grounded projection으로 교체했다. 별실에서는 `각자 씻고 편한 옷을 입었다.`와 실제 통화 문장만, 서울에서는 `가방은 가벼웠다.`, 가까운 식당·카페·귀가 사실만 출력한다. 원문 참조는 유지하고 배제 조건은 내부 stageAction 또는 상태 계약에 남겼다.

부산 별실과 서울 당일 데스크톱은 PASS다. DAY22 전체는 미여행·거절 경로와 모바일 의미 경로가 남아 **PARTIAL**이다. 다음 시작점은 연락 불가 미여행과 연락 가능 미여행 데스크톱 비-SKIP QA다.

## 미여행 연락 가능 · 연락 불가 후속 — 2026-09-06

fixture에 `Neutral · 미여행 · 연락 가능`과 `Distant · 미여행 · 연락 불가`를 추가했다. 연락 가능 상태는 DAY21의 실제 `rest_separately` 결과를, 연락 불가 상태는 DAY17 SOLO부터 DAY18~21의 무연락 이력을 production reducer로 완주한 결과를 사용한다.

### 연락 가능

- 실제 화면에서 C3~8을 선택해 DAY23까지 SKIP 없이 완주
- C5에서 하은 전송을 선택한 뒤에만 `오늘 본 풍경을 하은에게 보냈다.`가 출력되고 `photoMessageSent=true`로 기록
- 하은 연락 C6은 해당 선택 뒤에만 노출되고, 선택하기 전에는 하은 대사가 나오지 않음
- 산책·식사·저녁 행동은 이미 고른 실제 결과형 문장으로 출력

### 연락 불가

- 실제 화면에서 C3~5, C7~8을 선택해 DAY23까지 SKIP 없이 완주
- C5는 `내 앨범에만 남기자.` 하나만 노출하고 하은·교류 상대 전송 선택을 제거
- C6과 하은 대화·인물은 통째로 생략하고 C5에서 C7으로 직접 진행
- 앨범 선택은 `photoMessageSent=false`를 유지

### 플레이 중 발견한 상태·텍스트 오류

- 미여행 본문에도 `산책을 고르면`, `연락을 쉬기로 했다면`, `상대가 없는 경우에는` 같은 원문 분기 설명이 일반 독백으로 남아 있었다. 모든 C3~8 반응을 확정된 선택 사실의 source-grounded projection으로 바꾸고 해당 메타 문구 비노출 회귀를 추가했다.
- C5에서 하은 또는 실제 사진 교류 연락처로 전송해도 `photoMessageSent`가 항상 `false`였던 상태 계약 오류를 수정했다. 앨범만 `false`, 실제 전송 대상은 `true`로 replay된다.

두 미여행 데스크톱 경로는 PASS다. 두 경로 모두 DAY23 진입을 확인했고 테스트 전 사용자 저장을 복원했다. DAY22 전체는 사진 보관 거절·공유 숙소 접촉 거절 데스크톱과 389×844 Friendly/Neutral/Distant/Mixed 의미 경로가 남아 **PARTIAL**이다.
