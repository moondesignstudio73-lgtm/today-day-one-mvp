# DAY18 문자/통화 구분 계획 — 2026-09-04 20:46

SCENE18은 원문상 통화인데 현재 문자 말풍선으로 나온다. 이번 범위는 이미 긴 대화로 들어가는 경로에서 통화 가능 여부를 문자로 묻고 명시 답변을 받은 뒤 음성 대사의 자막 표현을 사용하는 것이다. 연기/연락 휴식/짧은 인사 경로를 통화로 바꾸지 않는다. 통화 불가의 별도 당일 시간 협의 분기는 후속 작업이다.

기존 입력/출력·저장 스키마는 유지한다. `dialogue`에 `device: call` 메타데이터를 추가하며 별도 전화 연결 서비스나 실제 음성 송신은 없다. 원문의 통화는 게임 내 사건이다. relation_future의 이미 존재하는 원문 대화를 통화로 표시한다.

UI 계획 (frontend-design 적용): 기존 VN 폰트/왼쪽 정렬/전체 폭 대화창을 유지한다. 문자만 작은 비대칭 말풍선을 사용하고 통화는 이름표의 “통화 ·”와 접근성 라벨로 구별한다. 기존 자주색 #282139, 밝은 글자 #ffffff, 하은 분홍 #ed5c91, 문자 배경 #624256를 재사용한다. 새 카드/전화기 장식/자동 파형은 추가하지 않는다. 이는 일반 전화 앱 제작이 아니라 이 게임의 원격 대사 구분이다.

검증: 통화 전 문자 협의→통화 자막→다음 독백 일반창 복원, 연락 휴식/연기에는 통화 없음, 저장 재생과 기존 문자 회귀. 화면 완료와 분기 전수 완료는 구분한다.
