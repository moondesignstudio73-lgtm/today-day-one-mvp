## 장면 계약

- 챕터 ID·시간·장소: DAY 1, 깨어난 직후부터 낮, 동일 병원 입원실.

- 극적 목적: 하은과의 물리적 거리를 플레이어가 결정하게 하고, 의료 안전·기억 확인·30일 재판단 목표를 행동으로 보여 준다.
- 이전 선택 콜백: 첫 접촉 선택 3종은 SCENE 01의 거리와 SCENE 05의 컵 보조 방식에 반영한다. 정보 우선순위 선택 3종은 의료진의 시선·기록 행동만 달리하고 과장된 새 포즈를 만들지 않는다.
- 정보 제한: 트럭, 하은의 사고 동승, 주인공의 보호 행동, 하은의 잠금 프로필과 후반 정체를 몸짓으로 암시하지 않는다.
- 감정 곡선: 정지된 피로 → 놀람과 충동적 접근 → 경계 재설정 → 전문적 확인 → 상실의 정지 → 생활적 협력 → 조심스러운 공동 결심.
- 후속 훅: 하은은 달력을 가리킨 뒤 물러서고, 주인공이 DAY 2의 도움 범위를 정할 공간을 남긴다.

## 블로킹 원칙

- 하은의 친밀함은 침대에 얼마나 가까이 서는지보다 상대의 허락에 맞춰 거리를 조절하는 행동으로 표현한다.
- 하은은 초반부터 등을 보인 채 휴대폰을 숨기거나, 문을 막거나, 그림자 속에서 내려다보는 자세를 취하지 않는다.
- 주인공은 침대에 누운 1인칭 시점이다. 상시 전신 스프라이트를 만들지 않고 손·컵·이불 반응은 필요할 때만 1인칭 레이어로 분리한다.
- 의료진은 침대 접근 동선을 확보하고 환자를 위압하지 않는다. 담당 의사와 간호사가 동시에 화면 중앙을 차지하지 않게 화자 중심으로 교대한다.
- 같은 감정의 대사마다 새 포즈로 바꾸지 않는다. 장면 목적, 거리, 접촉 권한, 사용 소품이 바뀔 때만 전환한다.
- 포옹, 컵 받침, 활력징후, 삼킴 검사는 정지 포즈 한 장으로 중요한 동작을 생략하지 않고 시작·접촉·종료의 짧은 연출 단위로 구현한다. 상세 타이밍은 PHASE 18에서 확정한다.

## 화면 배치·레이어 규칙

- 기본 병상 배경에서 하은은 중앙 또는 화면 오른쪽, 의료진은 문 쪽에서 반대편으로 진입한다. 정확한 좌우는 PHASE 16 기존 배경 감사 뒤 확정한다.
- 화면 하단 28% 대화 UI와 손동작이 겹치지 않도록 상체·손 핵심 동작을 중앙 높이에 둔다.
- 동시 등장 우선순위는 현재 화자 > 환자 안전 행동 > 반응 인물이다. 세 인물 전신을 억지로 한 화면에 넣지 않고 필요하면 반신 크롭과 화자 교대를 사용한다.
- 손·소품 레이어의 앞뒤 순서는 `배경 → 비화자 → 화자 몸 → 팔/손 → 상호작용 소품 → 표정/입 애니메이션 → UI`를 기본으로 한다. 포옹은 인물 교차가 있으므로 PHASE 18에서 전용 마스크를 지정한다.
- 좁은 화면에서는 전신보다 얼굴과 접촉 권한을 보여 주는 손을 우선한다. 손이 잘려 허락 전·후 차이를 알 수 없으면 해당 크롭은 불합격이다.

## 기술·일관성 기준

- 표정 교체가 가능한 포즈는 머리·목·어깨 기준점을 고정해 PHASE 13 얼굴 레이어와 정확히 결합되어야 한다.
- 신규 제작이 필요하면 투명 배경, sRGB, 긴 변 2048px 이상의 마스터를 사용하고 배포 규격은 PHASE 16 렌더러 감사 뒤 확정한다.
- 동일 의상에서 체형, 어깨 폭, 팔 길이, 손가락 수, 광원 방향, 선 굵기와 채색 밀도를 고정한다.
- 포즈 파일명 후보는 `<character>-pose-<state>-2d.png`, 손·소품 레이어는 `<character>-gesture-<state>-2d.png` 형식을 사용한다. 최종 이름은 기존 매니페스트 규칙에 맞춘다.
- 앉기·서기 전환에서 캐릭터의 화면상 키가 바뀌는 것은 허용하되 얼굴 크기가 장면마다 임의로 변하지 않게 카메라 스케일을 유지한다.

## 수량·재사용 판정

- 이하은: 9개 행동 기준 포즈. 기본 몸통 4~5종과 교체형 팔·손 레이어로 통합 가능한지 PHASE 16에서 감사한다.
- 담당 의사: 2개 포즈.
- 간호사: 3개 포즈.
- 주인공 1인칭 손: 3개 상태 레이어.
- 총 적합성 확인 대상: 캐릭터 14포즈 + 1인칭 손 3상태.

PHASE 16 전에는 위 수량을 모두 신규 생성 대상으로 확정하지 않는다. 기존 에셋의 분위기만 맞아도 채택하지 않으며, 표정 결합, 손 정확성, 병상 구도, 접촉 권한 가독성, 의료 안전성을 함께 검사한다.

## 완료 기준

- 잠금된 6개 Scene의 핵심 행동과 공간 변화가 포즈 큐에 매핑됐다.
- 첫 접촉 선택 3종이 SCENE 01 거리와 SCENE 05 컵 보조 방식에서 시각적으로 구분된다.
- 포옹·삼킴 검사·컵 보조의 의료 안전 및 시작·접촉·종료 단위가 정의됐다.

- 표정 결합, 손·소품 레이어, 화면 크롭과 기존 에셋 감사 기준이 정의됐다.
