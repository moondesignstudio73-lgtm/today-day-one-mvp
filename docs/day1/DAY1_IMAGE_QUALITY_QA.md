- 배경 2종과 컵 보조 컷인은 현재 후보로 합격했다.
- 첫 눈맞춤과 30일 재판단 CG는 의상·블로킹 결함을 `v2`에서 수정해 후보 합격했다.
- 하은 표정·포즈 시트와 의료진 시트는 최종 스프라이트로 불합격이다.
- 불합격 스프라이트가 남았으므로 PHASE 17은 완료 처리하지 않으며 PHASE 18로 넘어가지 않는다.

## 교차 일관성

- 배경과 승인 CG는 창문 왼쪽, 문 중앙, 수납장·모니터 오른쪽, 의자 왼쪽의 공간 구조를 유지한다.
- 하은은 보라색 턱선 단발, 보라색 눈, 금색 목걸이, 베이지 카디건과 흰 상의로 동일 인물로 읽힌다.
- 승인 CG의 하은은 놀람·안도·생활적 배려·존중하는 거리로 읽히며 초기 악역 코딩, 결혼 확정 연출, 숨겨진 휴대폰 신호가 없다.
- 날짜·병원명·차트·프로필·후반 반전 정보는 판독 가능하게 노출되지 않는다.

## 투명도 실측

16픽셀 간격 표본 검사 결과:

| 파일 | 포맷 | alpha 0 | 부분 alpha | alpha 255 |
|---|---|---:|---:|---:|
| 하은 표정 v1 | 24bpp RGB | 0 | 0 | 6,240 |
| 하은 포즈 v1 | 24bpp RGB | 0 | 0 | 6,144 |
| 의료진 포즈 v1 | 32bpp ARGB | 4,941 | 1,203 | 0 |

RGB 두 파일의 `alpha 255` 표기는 이미지 전체가 불투명하다는 뜻이며 체크무늬 역시 배경 픽셀이다. 의료진은 반대로 캐릭터 본체까지 완전 불투명하지 않다.

## 수정 시도와 중단 사유

- 내장 이미지 생성으로 하은 표정 시트 투명화 편집 1회와 참조 기반 신규 생성 1회를 시도했다.
- 첫 시도는 다시 24bpp RGB 체크무늬를 만들었고 두 번째 시도는 불투명 보라색 배경을 만들었다.
- PHASE 16 최초 생성까지 포함해 같은 근본 원인인 실제 알파 배경 생성 실패가 세 번 확인됐으므로 추가 반복 생성을 중단했다.
- 실패 출력은 프로젝트에 복사하지 않았다. 원본 후보와 사용자 에셋은 삭제·이동·덮어쓰기 하지 않았다.

## PHASE 17 완료에 필요한 결정

다음 실행 전에 아래 중 하나가 필요하다.

1. 투명 알파를 안정적으로 만드는 별도 아트 제작·후처리 경로를 허용한다.
2. 사용자가 투명 PNG 하은 표정·포즈와 의료진 스프라이트를 제공한다.

불투명 체크무늬나 반투명 인물을 그대로 게임에 연결하는 선택은 품질 기준을 낮추므로 허용하지 않는다.
