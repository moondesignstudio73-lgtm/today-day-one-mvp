## 검수 범위

- 첫 접촉 전략 3종 × 첫 질문 전략 3종의 9개 경로를 각각 새 저장 공간에서 시작해 결말까지 실행했다.
- 첫 선택 직후와 두 번째 선택 직후 저장·불러오기에서 전략 플래그와 후속 분기가 유지되는지 검사했다.
- SKIP, 키보드 Enter 선택, 390×844 CSS viewport, 오디오 토글, CG·자동 큐 입력 잠금, 콘솔 오류를 검사했다.
- 잠금본의 6개 Scene, 정보 공개 순서, 결말의 `지금의 내가 다시 판단한다 → 나부터` 훅을 변경하지 않았다.

## 상호작용·복원 검사

- **중간 저장:** 첫 접촉 선택 뒤 시스템 메뉴에서 저장하고 페이지를 다시 연 뒤 불러왔다. 선택 반응 시작점으로 복구됐고 SKIP 후 두 번째 선택 화면과 3개 질문이 정상 표시됐다.
- **키보드:** 첫 선택 버튼에서 Enter를 눌러 다음 분기로 진행했다. 상위 대화창의 Enter 처리와 충돌하던 결함을 수정했다.
- **SKIP:** 각 세그먼트에서 다음 선택 또는 Scene 종료까지만 이동하며 선택을 건너뛰지 않았다.
- **CG·자동 큐:** CG와 캐릭터·SFX 자동 큐 동안 입력을 잠가 중복 클릭이 시퀀스를 앞지르지 않도록 했다. 스킵·종료 시 잠금과 타이머가 함께 정리된다.
- **모바일:** 390×844 viewport에서 상단 메뉴, 3개 선택 버튼, 캐릭터·배경, 대사창이 화면 안에 표시되고 선택 가능한 것을 시각 확인했다.
- **오디오:** `사운드 켜기 → 사운드 끄기` 상태 전환과 DAY 1 큐 호출을 확인했다.
- **브라우저 오류:** 대표 모바일·저장 복원 경로의 콘솔 error 0건.

## 발견 결함과 수정

1. CG와 짧은 자동 큐가 표시되는 동안 스테이지를 연속 클릭하면 타이머보다 먼저 다음 스텝으로 진행할 수 있었다. `StoryCg`와 `StoryAutoCue` 입력 잠금을 추가했다.
2. 선택 버튼의 Enter 기본 클릭이 상위 대화창 keydown 처리에 막혔다. 선택 레이어가 Enter/Space를 직접 처리하고 상위 이벤트 전파를 멈추도록 수정했다.
