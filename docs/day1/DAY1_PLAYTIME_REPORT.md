판정: **PASS — 9.25~9.60분**

## 측정 방식

`scripts/measure-day1-playtime.mjs`가 실제 `src/day1-campaign-runtime.mjs`의 실행 시퀀스를 경로별로 조립해 다음 시간을 합산한다.

- 한국어 보통 읽기 속도: 분당 340자
- 대사·내레이션: 글자 수 기반 읽기 시간 + 줄 전환 인지 0.5초, 최소 체류 1.4초
- 런타임 고정 연출: Scene 전환 1.08초, CG의 실제 `duration`, 캐릭터 입장 0.42초, NPC·SFX·BGM 자동 큐의 실제 대기값
- 선택 숙고: 선택 시점당 5초, 총 2회

타이핑은 읽기와 동시에 진행되므로 별도 중복 합산하지 않았다. SKIP이나 AUTO는 사용하지 않았으며, 실제 게임 데이터·분기·연출 시간을 읽는 계측형 연속 플레이 모델이다.
