- 별도 컨텍스트 콜드리드는 검증 실패 후 부분 변경 잔존, 공개 자료 제안 재호출의 체크포인트 되감기, 선택 이력 미러 약화를 지적했다. 원자적 복구, 멱등 제안, 미러 검증 테스트로 모두 교정했다.
