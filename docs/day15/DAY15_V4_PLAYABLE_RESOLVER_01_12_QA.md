# DAY 15 V4 SCENE 01~12 정확 원문 경로 resolver QA

상태: `EXACT SOURCE ROUTE RESOLVER PASS · IMMERSIVE ADAPTER CONNECTED`

## 이해 잠금

- Understood as: 최신 Notion 하위 본문에서 잠근 SCENE 01~12 정본을 다시 쓰거나 요약하지 않고, 실제 저장 상태가 허용하는 초대/비초대, 참석/자기 오후, 선택 1~7 반응만 하나씩 출력한다. 기존 축약 데이터의 문장으로 빈 곳을 메우지 않으며 모순 상태는 fail-closed한다.

## 최신 원고와 정본

- 작업 직전 `AI해커톤 > DAY 15 — 빛나는 쪽을 보다 | SCENARIO V4` 하위 페이지를 새로 완전 조회했다. 페이지 ID `3c9c31f0-29a6-8138-ab56-ed8ee668526d`, 스냅샷 `2026-08-27T21:19:12.202Z`로 직전 잠금과 동일하다.
- 상위 페이지 Markdown 첨부와 `<file>` 블록은 원고로 사용하지 않았다.
- 입력 정본은 `day15-v4-source-registry-01-12.mjs`의 LF 정규화 원문이다. resolver는 원문 문자열을 수정하지 않고 표제 경계와 원고 내부 분기 마커로 선택한 구간만 projection한다.

## 구현 계약

- SCENE 01은 초대/비초대 문단과 해당 선택 1 반응 하나만 남긴다. 비초대 경로는 현장 초대를 발명하지 않는다.
- SCENE 02는 선택 2 반응을 하나만 남기고 자기 오후에서만 원고의 별도 의상 마무리를 붙인다.
- SCENE 03·06은 참석/자기 오후를 배타적으로 선택한다. 자기 오후 SCENE 06은 저장된 선택 3~5 반응을 원고 순서로 재생하고 첫 미선택 관문 하나만 노출한다.
- SCENE 04·07·09·11·12는 각각 선택 3·4·5·6·7의 저장 ID와 이력 mirror를 검증하고 해당 반응만 남긴다.
- SCENE 10의 `LEAVE`는 원고가 제공한 `먼저 쉬는 자리`를 사용한다. 기존 축약본이 추가했던 `먼저 나가자는 말을 거두고` 문장은 가져오지 않는다.
- 참석 전용 장면, 대화 전용 SCENE 12, 초대별 선택 ID, 참석/자기 오후 대체 선택 ID가 맞지 않으면 장면을 생략하거나 오류로 차단한다.
- SCENE 05·08은 전체 경로 공통이 아니라 참석 경로 내부 공통인 `attendanceCommonScenes`다. 자기 오후에서는 활성화하지 않는다.
- 모든 소스 경계 마커는 정확히 한 번 존재하고 예상 순서에 있어야 한다. 중복·역전은 fail-closed하며, 선택 표제만 제거하고 서사의 정당한 `- ` 시작 행은 보존한다.
- 결과는 `active`/`omitted`를 항상 명시한다. SCENE 06의 복수 저장 선택은 `selectedChoiceIds`와 선택 번호별 반응으로 보존한다.

## SIP 자체 검증

- 무맥락 냉독이 참석 공통 장면의 모호한 명칭, 광범위한 하이픈 제거, 마커 중복 묵인, 다중 선택 결과의 단수 ID 모호성을 지적했다. 각각 메타데이터, 구조 보존, fail-closed 검증, 복수 ID 계약과 회귀 테스트로 교정했다.
- 정확 원문 정본은 소스 레지스트리이고 resolver는 상태별 projection이라는 SSOT 관계를 재확인했다. 승인 없는 구조 통합은 하지 않았다.
- 집중 검증은 `57 PASS / 0 FAIL`이다. 허구 정본과 저장소 동작만 다뤄 외부 사실 검증은 적용하지 않았다.
