## SIP 판정

무맥락 냉독에서 기존 V4 재호출의 파괴적 덮어쓰기, 부분 V4의 신규 초기화 오판, 참석자의 직접 관찰까지 지우는 무연락 조건을 발견했다. 초기화는 `V4_NEW`에서만 쓰도록 바꾸고, 모든 `day15V4*` 일부 흔적은 검증 대상으로 보내며, 직접 관찰 금지는 `OWN_AFTERNOON + NO_CONTACT`로 좁혔다. 세 회귀를 집중 테스트에 추가했다.

SSOT 읽기 전용 감사에서 실행 상수·선택 ID·기초 상태 검증의 정본은 두 신규 모듈이고, 문서는 구현 계약과 검증 설명으로 유지됨을 확인했다. 중복 제거를 위한 문서 구조 변경은 현재 승인 없이 수행하지 않았다. 외부 현실 주장을 포함하지 않는 게임 원고·저장소 동작 계약이므로 `factchk`는 적용 대상이 아니다.
