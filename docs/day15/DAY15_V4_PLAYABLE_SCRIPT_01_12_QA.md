## SIP 판정

무맥락 냉독은 선택 프롬프트 중복, 선택 반응 뒤의 중복 프롬프트, 참석 경로의 불참 선택 오염, `LEAVE`를 `SEPARATE`로 처리하는 폴백을 지적했다. 프롬프트를 미선택 관문당 하나로 제한하고 참석 SCENE 06의 불참 반응을 차단했으며, 출구 경로를 명시적으로 분리하고 세 회귀 테스트를 추가했다.

읽기 전용 SSOT 이중 검색에서 선택 ID와 효과의 정본은 `src/day15-v4-campaign-data.mjs`, 장면 플레이 데이터의 정본은 이번 모듈, 상태 유효성의 정본은 `src/day15-v4-state-contract.mjs`임을 확인했다. 문서의 `0/24` 표현은 이번 구현 전 상태라 현재 판정으로 갱신하며, 승인 없는 구조 통합은 하지 않는다. 외부 현실 주장이 아니라 게임 원고와 저장소 동작만 다루므로 `factchk`는 적용하지 않았다.
