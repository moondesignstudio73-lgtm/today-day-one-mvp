## 관계 조건부 대사와 접촉

LOW/MID/HIGH는 사실을 바꾸지 않고 말의 온도·침묵 길이·직접성만 조절한다. LOW는 확인과 거리 존중, MID는 서로의 불안을 고쳐 말하는 생활감, HIGH는 해결된 경계 뒤 작은 장난과 가까운 귀가를 허용한다. 어느 밴드에서도 하은의 전시 선택, 혼자 있을 권리, 갈등 종료, 자료 공유가 주인공의 권리로 바뀌지 않는다.

어깨 접촉은 `기존 친밀 접촉 성립 && DAY13 거리두기 없음 && DAY15 경계 해결 && 하은 이탈 아님 && 하은이 가까운 귀가를 선택`을 모두 만족할 때만 발생한다. 포옹·키스는 없다. 자격과 실제 발생은 별도 상태다.

## Voice Profile

- 주인공: 웃음·자리·말실수를 관찰하고 가능한 의미를 분리한 뒤 묻는다. 관찰 → 가능성 → 확인 → 판단 → 행동 순서를 지키며 시우를 깎아 자기 자리를 만들지 않는다.
- 하은: 전시를 보는 자기 방식과 시우와의 현재 관계를 숨기지 않는다. 생활적인 다정함과 짧은 장난이 있지만 통제 요구 앞에서는 멈추거나 떠날 수 있다.
- 시우: 33세 크리에이티브 디렉터이자 유능한 선배다. 전문적인 설명과 좌우 실수를 함께 가진 사람이며 연애 악역이나 진실 해설자가 아니다.
