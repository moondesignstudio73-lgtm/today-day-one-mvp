## 제작 및 검수 결과

- 지도에서 발견한 전체 장소: 61개
- 최종 제작 이미지: 61개
- 제작하지 못한 장소: 없음
- 재생성한 이미지: 없음
- 지도 데이터 문제: 배경 에셋 연결 정보가 장소 데이터와 분리되어 있지 않았음. `src/map-location-assets.mjs`를 추가해 장소 ID와 배경을 일대일로 연결함.
- 중복·불분명 장소: 역, 카페, 백화점처럼 범주가 같은 장소가 있으나 ID와 고유 이름이 명확하여 중복으로 처리하지 않음.
- 추가 제작 후보: 현재 지도 데이터 밖의 스토리 전용 배경은 이번 범위에서 제외함.

## 공통 생성 프롬프트

Built-in ImageGen을 사용했다. 모든 장소별 프롬프트에 `stylized-concept`, 16:9 게임 배경, 현대 대한민국, 고품질 극장용 3D 애니메이션 환경, 부드러운 전역 조명, 와이드 아이레벨 구도, 캐릭터 배치 여백을 공통 적용했다. 또한 사람·NPC·직원·손님·행인·실루엣·군중·인물 반사·인물 사진을 금지하고, 읽을 수 없는 간판·로고·워터마크를 배제했다.
