# DAY 18 V4 SCENE 17~18 휴대전화 행동 구현

## 원문 대조

- SCENE18에서 하은의 침묵 뒤 주인공이 화면이 꺼졌는지 확인하고, 하은이 “듣고 있어.”라고 답한다.
- 선택 12 직전 주인공은 휴대전화를 쥔 손을 바꾸고, 남의 선택 뒤에 자기 선택을 숨길 수 없다고 생각한다.
- 두 항목은 발화가 아니라 화면 확인과 손동작이다. 일반 대화창의 대사로 만들지 않는다.

## 구현

- 기존 `phoneCallCue: silence`를 화면 확인 연출로 재사용했다. 빈 통화 화면과 접근성 라벨이 실제 대사를 덮어쓰지 않고 1.2초 뒤 “듣고 있어.”로 이어진다.
- 새 `phoneCallCue: grip-shift`는 통화 UI를 좌우로 짧게 이동해 손을 바꾸는 촉각적 움직임만 표현한다. 손 CG를 새로 만들지 않아 사진식 POV 손이 재발할 경로를 추가하지 않는다.
- 직후 원문 내적 반응을 narration으로 복원한 뒤 선택 12로 이어진다.
- `prefers-reduced-motion`에서는 이동 애니메이션을 제거하되 순서와 접근성 라벨은 유지한다.

## 회귀 계약

- `silence < “듣고 있어.” < grip-shift < 원문 내적 반응 < 선택 12` 순서를 유지한다.
- 화면 확인과 손 바꾸기를 일반 `dialogue` 텍스트로 출력하지 않는다.
- 통화 불가·연기 경로에는 이 cue를 넣지 않는다.
- 새 손 포함 이미지를 사용하게 되면 `STORY_V4_IMAGE_STYLE_RULES.md`의 해부학/화풍 이중 관문을 먼저 통과해야 한다.
