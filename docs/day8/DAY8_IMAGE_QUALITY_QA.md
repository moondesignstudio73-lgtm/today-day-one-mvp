# DAY 8 신규 배경 이미지 품질 검사

판정: `IMAGE QA PASS`

## 대상

- 파일: `assets/backgrounds/day8/day8-household-store-day-v1.png`
- 생성 방식: built-in ImageGen 신규 생성 후 라벨 문자 제거 정밀 편집 2회
- 용도: DAY 8 S05 회원 번호 확인, S06 현재 기준 세제 선택·결제

## 원본 해상도 검사

- 형식: PNG / RGB
- 크기: `1672 × 941`
- 화면비: 약 `1.7768:1`, 16:9 허용 오차 PASS
- 파일 크기: `2,083,839 bytes`
- 최소 1600×900 기준 PASS

## 육안 검사

| 항목 | 결과 | 근거 |
|---|---|---|
| 장소 의미 | PASS | 세제·수건·청소도구가 정돈된 소규모 동네 생활용품점이며 패션숍·백화점·편의점으로 보이지 않음 |
| 시간·조명 | PASS | 맑은 오전 자연광과 따뜻한 실내광, 공포·야간·병원 인상 없음 |
| 무인 배경 | PASS | 인물·손·실루엣 없음 |
| 문자·상표 | PASS | 인물·문자·상표 없음. 최종본의 포장과 선반표는 빈 면 또는 추상 원·곡선만 사용 |
| 상품 비교 | PASS | 왼쪽·중앙에 대용량 병과 소용량 파우치가 함께 있어 현재 기준 비교 행동을 화면으로 지지 |
| UI 안전 여백 | PASS | 중앙~우측 바닥과 통로가 넓어 대화 UI와 소품 close-prop을 가리지 않음 |

| 금지 요소 | PASS | 고급 금장, 의류·신발, 감시 구도, 미스터리 단서, 워터마크 없음 |

## 수정 이력

1. 초안은 공간·조명·구도 PASS였으나 일부 포장에 글자형 무늬가 있어 탈락.
2. 전체 라벨을 추상 도형으로 교체했으나 왼쪽 흰 파우치에 미세한 글자형 흔적이 남아 탈락.
3. 해당 흔적을 빈 원형 라벨로 교체하고 전체 화면을 원본 해상도로 재검사해 최종 PASS.

## 최종 생성 프롬프트 요약

밝은 월요일 오전의 소규모 한국 동네 생활용품점, 세제·수건·청소용품 진열, 무인 16:9 2D 비주얼노벨 배경, 중앙·우측 UI 여백, 인물·읽을 수 있는 문자·숫자·가격·상표·로고·워터마크 없음, 모든 라벨은 추상 도형만 사용.

최종 판정: S05·S06용 생활용품점 배경의 이미지 품질 PASS. 자산 매니페스트 등록과 프레젠테이션 `ready` 전환 허용.
