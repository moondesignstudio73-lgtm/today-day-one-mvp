## 오디오·연출

- BGM은 `daily`와 `dateShopping`만 사용한다. S12~14 갈등도 공포·추적·이명·색수차 없이 생활 데이트 리듬 안에서 0.05~0.06으로 낮춘다.
- 재사용 SFX: `SFX_SPARE_PHONE_KEY`, `SFX_AUTO_DOOR`, `SFX_PHOTO_FRAME`, `SFX_BAG_ZIPPER`, `SFX_DOCUMENT_RECEIVE`, `SFX_CUP_SET_DOWN`, `SFX_PENCIL_NOTE`, `SFX_HOME_KEY_UNLOCK`.
- 선물 거절에 호감 보상음·장착음·위기 경보를 붙이지 않는다. 교환은 문서/봉투 소품음 한 번만 사용한다.
- 스카프 선구매, 교환, 녹색 셔츠 구매를 서로 다른 계산음으로 중복 강조하지 않는다. 실제 거래 어댑터 결과가 확정된 뒤 최종 영수증 연출 한 번으로 끝낸다.
