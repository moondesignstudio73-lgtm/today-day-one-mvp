# 자유연애 이벤트 구성

이 문서는 자유연애 모드 이벤트의 발생 구조와 전 여자친구 이벤트 검토안을 분리해서 관리하기 위한 자료다.

## 발생 그룹

이벤트 검토 순서는 다음과 같다.

1. 저녁 전 랜덤 이벤트
2. 장소 이동 시 이벤트
3. 신뢰도 200 이하 이벤트
4. 직장동료 유혹 이벤트
5. 친구의 조언 이벤트
6. 친구 관련 이벤트

상세 분류와 개별 검토 메모는 루트의 `free-romance-event-structure.html`에서 확인한다. 해당 HTML은 `scripts/generate-free-romance-event-structure.mjs`로 다시 생성할 수 있다.

## 공통 제안 규칙

- 이벤트당 고정 배경 1개
- 장면 전환 없음
- 질문 2개
- 질문마다 짧은 선택 답변 2개
- 저녁 전 랜덤 이벤트는 하루 최대 1회
- 장소 이벤트는 지정 장소 입장 시에만 판정
- `우산 하나로 걷는 귀갓길` 이벤트는 검토 목록에서 제외

## 전 여자친구 유리 이벤트

| 항목 | 설정 |
| --- | --- |
| 이벤트 ID | `situation-ex-girlfriend-reunion` |
| 표시 이름 | 전 여자친구 유리와의 우연한 재회 |
| 등장인물 | 유리 |
| 제안 기간 | DAY 7~23 |
| 제안 발생 장소 | 지도 내 카페 |
| 제안 확률 | 카페 입장 시 50% |
| 반복 | 1회 발생 후 종료 |
| 화면 | 카페 배경 1개, 전환 없음 |

### 선택 결과 제안

- 유리의 유혹을 받아들이면 유리 호감도 `+15`
- 유혹을 거절하면 유리 호감도는 상승하지 않음
- 거절 선택은 현재 연인과의 신뢰를 지키는 방향으로 처리

## 구현 상태

검토 HTML의 구조는 실제 자유연애 로직에 반영되어 있다.

- 자유연애 이벤트를 6개 발생 그룹으로 분리
- 일반 랜덤 이벤트는 저녁 전 하루 최대 1회 판정
- 장소 전용 이벤트는 지도에서 해당 카테고리 장소에 입장할 때만 판정
- 신뢰도 200 이하 이벤트와 직장동료 관심도 조건 분리
- 친구가 있는 카페 방문형 조언 이벤트 2개 추가
- 이벤트당 고정 배경 1개, 화면 전환 없음, 질문 2개와 최종 답변 2개
- `우산 하나로 걷는 귀갓길` 이벤트 제외
- 카페 입장 시 유리 재회 이벤트 50% 판정
- 유리의 유혹 수락 시 유리 호감도 `+15`
- TIP 게임도구 NPC 상세 화면에서 관련 이벤트 강제 실행 가능
