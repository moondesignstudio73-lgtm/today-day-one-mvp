## 핵심 감사 결과

1. 계정 복구를 보상 장면으로 처리하지 않고 공식 명의, 현재 명세, 생활비 소유권, 접근 범위를 차례로 확인하는 생활 행동으로 구성했다.
2. 주인공은 잔액을 즉시 보지만 사용 가능한 예산이라고 단정하지 않는다. 확인 가능한 사실과 돈을 움직일 권한을 분리한다.
3. 하은은 과거 비밀번호나 분담 기억을 근거로 밀어붙이지 않는다. 카드·영수증·계산기 농담으로 긴장을 낮추면서 현재 동의를 존중한다.
4. DAY 11의 9개 선택은 확인 시간, 일정 겹침 처리, 공유 범위와 재검토 주기로 각각 회수된다.
5. 세 선택은 공식 확인 전략, 비용 분류 전략, 접근 권한 전략으로 서로 다른 행동 비용과 후속 상태를 만든다.

## 정보 장부 검사

- `FACT`: 공식 명의·발행일, 본인 확인 뒤 현재 잔액·이번 달 명세.
- `PARTIAL FACT`: 공동생활에서 함께 사용한 흔적이 있는 비용.
- `UNKNOWN`: 과거 분담 약속, 오래된 거래 목적, 공동 자산의 법적 소유권.
- `BOUNDARY`: 열람 권한, 이동 권한, 투자 판단, 공동 소유 판정은 각각 별도다.
- `PROHIBITED INFERENCE`: 관계 기억만으로 공동 책임·기만·범죄를 확정하는 해석.
