# DAY18 메모 SKIP 잔상 수정 — 2026-09-04 22:59 실행

음식 행동 추가 전 최근 개인 메모 UI의 전환 경로를 검토하던 중 SKIP이 일반 renderImmersiveStep 정리를 우회함을 발견했다. 실제 game198에서 하은 통화 연기 → 시간 미정 → 메모 → SKIP으로 재현했다. 여행 선택이 생겨도 메모 패널이 남아 선택 위를 덮고 일반 대화창과 접근성 이름도 복원되지 않았다. HIGH UI 오류로 행동 에셋보다 먼저 수정한다.

입력/출력·저장/시나리오 계약 변화 없음. 메모 제거/클래스/접근성 이름 복원을 작은 공통 정리 함수로 옮겨 일반 다음 단계, SKIP의 대화 표시 복원, 장면 종료에서 호출한다. 메모가 없으면 아무 영향이 없어야 한다.

실제 메모 SKIP→선택 조작/저장 재개, 정리 함수 반복 호출 및 세 진입점 자동 검사. 이 SKIP 시험은 원문 4경로 비-SKIP 검증과 별도이며 DAY18 PARTIAL 유지.
