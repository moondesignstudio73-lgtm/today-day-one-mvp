집에 돌아오자 하은은 생활용품점에서 찍어 둔 컵 사진을 화면에 띄운다. 가격 아래에는 아직 빈 선물 규칙 칸이 있다.

**하은**
자, 세 번의 신분 심사를 견딘 컵. 선물 규칙은 어떤 걸로 할까?

**주인공**
놀라움을 남길 수는 있어도 결제 동의는 생략하지 않는다.

## 선택 3 — 선물 동의 방식

### `spend14_consent_ask_first`

> 선물은 품목·가격 범위를 먼저 물은 뒤에만 산다.

**주인공**
품목과 가격 범위를 먼저 묻자. 동의하면 색만 비밀로 남겨.

**하은**
상자를 열 때는 놀라고, 결제 알림을 볼 때는 안 놀라는 방식.

[STATE: `day14ConsentStrategy=spend14_consent_ask_first`]
[FOLLOW-UP: 선물 후보는 사전 동의 전 결제 불가.]

### `spend14_consent_wishlist`

> 서로의 현재 위시리스트를 각자 수정할 수 있게 만든다.

**주인공**
서로 공개한 위시리스트 안에서 고르자. 목록 밖은 다시 묻고.

**하은**
선택권은 내가 두고, 조합은 네가 숨기는 거네.

[STATE: `day14ConsentStrategy=spend14_consent_wishlist`]
[FOLLOW-UP: 위시리스트 범위와 갱신일을 저장한다.]

### `spend14_consent_no_surprise`

> 오늘은 선물을 사지 않고 필요한 것만 기록한다.

**주인공**
오늘은 선물을 사지 않고 필요한 것만 기록하자. 선물 후보는 다음에 다시 물을게.

**하은**
좋아. 사지 않는다고 마음이 부족한 건 아니니까, 컵은 사진만 남겨 두자.

[STATE: `day14ConsentStrategy=spend14_consent_no_surprise`]
[FOLLOW-UP: 오늘 선물 결제는 0이며 필요한 품목 기록만 남긴다.]

**주인공**
선택 변경 가능 시간과 사진 공유 범위도 같이 정하자.

## 감정 곡선과 자체 QA

- 가벼운 공동 실험 → 구체적 선택 → 작은 위화감과 합리적 보류 → 할인 압박을 함께 통과 → 선물 경계 합의 → 다음 여가에 대한 기대.
- 8개 Scene Beat, 3개 행동 전략 선택군, 각 3개 선택 반응과 후속 상태를 포함한다.
- DAY 13의 예산 기준·분담·검토 3×3 콜백을 모두 포함한다.
- 추천 위화감은 복수의 생활적 출처를 열어 두며 하은을 의심 대상으로 연출하지 않는다.
- 주인공은 관찰→가능성→확인→판단→행동 순서를 완료한다.
- 반복 요약이나 긴 정지로 분량을 채우지 않고 실제 이동·비교·결제·검토·합의 행동으로 구성한다.
- 내러티브 QA와 시나리오 잠금 판정은 완료했다. `NEEDS FIX: 0`이며 다음 관문은 기존 에셋 감사·연출/오디오 매핑이다.
