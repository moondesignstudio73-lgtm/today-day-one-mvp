# DAY 14 V4 구현 격차·콘텐츠 커버리지 감사

권위·분기 계약: `docs/day14/DAY14_NOTION_SOURCE_LOCK_V4.md`

이 감사는 전체 대본을 대신하지 않는다. 구현자는 작업 직전 잠금 문서에 기록된 Notion 하위 페이지 본문을 다시 완전 조회하고, 그 본문으로 장면·대사·선택 데이터를 작성해야 한다.

상태: `AUDIT PASS · REBUILD REQUIRED`

## 결론

현재 DAY 14 신규 시작 런타임은 Notion V4와 직접 대응하는 장면이 `0/22`다. 기존 구현은 8장면·3선택의 생활용품 소비/예산 챕터이며, 최신 원고의 꽃·하은의 좋지 않은 업무 하루·나리 첫 만남·대면/통화/완전휴식 분기를 구현하지 않는다. 신규 진행은 V4로 교체하고 기존 V1은 이미 저장된 `m30-day14-current-choice-spending` 세션과 선택 필드의 복원 전용 레거시 경로로 유지한다.

## 재사용 가능한 실제 게임 표면

| 요소 | 저장소 근거 | V4 통합 방식 | 분류 |
|---|---|---|---|
| 플로라 카페 | `flower-cafe`, `assets/backgrounds/map-locations/020_flower-cafe.png` | 꽃 팝업·나리 첫 대면·하은과 조용히 앉는 사건의 중심 장소 | 필수/조건부 |
| 연희역 | `yeonhui-station`, `018_yeonhui-station.png` | 대면 후 귀가·손잡기 또는 비접촉 작별 | 조건부 |
| 나의 방 | 기존 주·야간 집 배경 | 책상 정리, 미외출, 꽃의 귀가, 자기 저녁과 밤인사 | 모든 경로 필수 |
| 나리/플로리스트 | 히로인 프로필과 `career-flower-delivery`, `career-bouquet` | 직업 기능 설명이 아니라 가격·포장·손질·실수의 생활 행동으로 재해석 | 외출 경로 필수 |
| 선물·소비 | 상점/아이템/경제 원장 기반 | 구매 의도→실제 지출→소유자를 분리하고 거절 시 주인공 꽃으로 귀가 | 외출 경로 선택 |
| 연락·사진 | 스마트폰·메시지·사진 동의 기반 | 모든 경로에서 연락 경계를 처리하되, 꽃 사진은 실제 촬영 경로에서만 존재시키고 휴식 경로에는 비생성을 저장 | 연락은 필수, 사진은 조건부 |
| 관계/접촉 | 하은 호감·신뢰와 기존 손잡기 기록 | 하은 선제 제안·미해결 경계 없음까지 만족할 때만 손잡기 | 고관계 조건부 |

단순 장소 방문이나 꽃 관리 튜토리얼은 추가하지 않는다. 각 재사용 요소는 관계 변화, 현재 행동 선택, 감정 반응, 후속 콜백 중 하나 이상을 실제 상태로 남겨야 한다.

## 최근 3 DAY 반복 방지

- DAY 11의 친구 앞 관계 공개, DAY 12의 직장 적응, DAY 13의 새로운 사진가와 현재 자기소개를 반복하지 않는다.
- DAY 14의 중심 경험은 `선물을 살지`가 아니라 `상대가 오늘 받지 않을 수 있을 때 무엇을 하는가`다.
- 나리는 아라처럼 주인공의 현재 정체성을 해방시키는 인물이 아니며, 소라처럼 하은을 설명하는 친구도 아니고, 윤서진처럼 과거 직장을 아는 인물도 아니다.
- 경제 설명은 가격 범위·실제 결제 가능 여부에만 제한하고 전체 본문의 20% 아래로 유지한다.

## V4 상태·호환 전략

- 신규 필드는 다음 챕터 계약에서 타입·기본값·enum·체크포인트까지 확정할 `day14V4*` 네임스페이스로 분리한다. 기존 `day14LaneStrategy`, `day14PurchaseStrategy`, `day14ConsentStrategy`, `day14CurrentChoiceSpendingCompleted`를 V4 선택으로 추정 변환하지 않는다.
- 신규 시작 선택기는 DAY 13 V3 완료/꽃 훅을 읽어 V4로 들어간다. V1 진행 중 또는 완료 저장은 기존 런타임·자유행동·DAY 15 V1 훅으로 복원한다.
- `haeunAffection`, `haeunTrust`, 이전 손잡기와 미해결 경계는 입력 조건이다. 접촉은 출력 보상이 아니다.
- `seojinAffection`, `seojinStatusInterest`, DAY 13 아라 플래그는 V4에서 변경하지 않는다.
- 구매·사진·나리 대면·하은 업무 청취 플래그는 서로 독립적으로 저장한다. `false`, 미경험, 미정 값을 섞지 않도록 정확한 표현은 다음 챕터 계약에서 고정하고 한 플래그로 다른 사실을 추정하지 않는다.
- 미외출/완전휴식 경로에서도 책상 정리·식사·밤의 선택이 남고 정상적으로 DAY 15에 도달해야 한다.

## 구현 순서

1. V4 챕터 계약, Voice Profile, 지식 장부, MUST/MAY/MUST NOT REVEAL, 감정 곡선과 10문항 QA를 잠근다.
2. SCENE 01~22 플레이 데이터와 선택 1~10의 조건부 활성 규칙을 코드화한다.
3. V4 상태 해석기·체크포인트·기존 V1 레거시 라우팅을 구현한다.
4. 플로라 카페·연희역·집, 나리, 꽃 구매/사진/연락/접촉을 프리모드 표면과 연결한다.
5. DAY 2 화면 기준으로 필요한 장면 전용 CG·POV와 캐릭터 자산을 감사하고, 부족한 자산만 Codex 내장 ImageGen으로 제작한다.
6. 집중·저장 복원·인접 DAY·전체 회귀·실제 브라우저·동일 SHA 배포를 순서대로 통과한다.
