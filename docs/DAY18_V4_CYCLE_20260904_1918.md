2. 유리 약속 미고지: 약속 유지 → 점심에 유리 공개 → 메뉴 더 보기 → 현재의 유리 궁금함 → 외로웠겠다는 말 → 하은과 관계 명시 → 재만남 요청 → 한 끼 대접 → 밤에 실제 대화 전달 → 확신 유보 → 가까운 하루 후보 → DAY19. 점심에는 하은이 처음 듣고 시점을 물었고, 밤에는 “네가 아는 그 저녁”으로 시작했다. 현재 관심과 유리의 미수락을 전달했다. 밤 관계 선택에서 새로고침/이어하기 후 같은 전달 내용과 선택을 복구했다.
