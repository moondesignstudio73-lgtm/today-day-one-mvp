## 핵심 불변식

- 마지막 선택 하나나 호감 점수 하나로 누적 관계·사실·상대의 현재 응답을 덮지 않는다.
- 결혼 준비 합의는 결혼식·혼인 완료가 아니다. 날짜·집·계약·수입·회복을 엔딩 보상으로 만들지 않는다.
- 상대가 오늘 나타나려면 실제 약속과 현재 만남 의사가 모두 있어야 한다. 종료한 관계에는 연락·대사·접촉을 생성하지 않는다.
- 접촉·사진·숙박·다음 약속은 각각 현재 동의를 기다린다. 과거 동의는 오늘 동의가 아니다.
- 새 연애와 알아가는 중, 답변 대기, 혼자를 서로 승격하지 않는다. 나리의 사업 연락은 연애 경로가 아니다.
- 미정정 사실은 자동 발각도 면죄도 하지 않는다. 정정 선택 뒤에도 상대의 듣기·시간 필요·종료 응답을 기다린다.
- 일·돈·몸은 연애 결과와 독립적으로 이어지고, 선택하지 않은 성공이나 완전 회복을 만들지 않는다.
- 조건문·경로 안내·편집 메모는 일반 대화창에 출력하지 않는다.
- 손 포함 CG는 `docs/STORY_V4_IMAGE_STYLE_RULES.md`의 전면 애니메이션 규칙과 승인 URL/검수 캐시 관문을 통과해야 한다.
