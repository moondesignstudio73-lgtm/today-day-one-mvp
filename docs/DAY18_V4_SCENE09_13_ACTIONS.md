# DAY 18 V4 — SCENE 09·13 식탁 행동 복구

2026-09-05 실행. DAY 18 전체 판정은 `PARTIAL`이다.

## 원본 대조

- SCENE 09: 유리가 웃음을 가라앉히며 냅킨을 접은 뒤 현재 관계를 묻고, 주인공은 컵을 바로 놓는다. 유리가 이미 하은을 아는 입력에서는 원문의 호칭 조건에 따라 `하은 씨`라고 묻는다.
- 흔들리는 마음을 말하면 유리는 답하기 전에 시선을 내린다. 기존 관계를 아는 유리에게 자유롭다고 말하면 손이 멈춘 뒤 정정 질문이 나온다.
- SCENE 13: 관련 유리 이력이 있는 경로에서 하은은 심사받는 기분을 말하기 전에 냅킨을 접는다. 좋은 마음에서는 표정 변화, 실제 다른 관심에서는 두 사람이 각자 더 먹을지 일어날지 정하는 멈춤, 확인 욕구에서는 빈 냅킨을 자기 쪽으로 당기는 행동이 있다.

## 구현

행동을 독백으로 바꾸지 않고 `storyActionCue`로 연결했다. 별도 사건·선택·관계 수치·연락 이력은 추가하지 않았다. 배경/인물의 작은 시선 이동과 밝기 변화만 사용하며, 행동 label은 접근성 이름으로만 노출된다.

추가 cue:

- `yuri-napkin-fold`, `cup-square`, `yuri-gaze-lower`, `yuri-hand-stop`
- `haeun-napkin-fold`, `haeun-expression-soften`, `meal-decision-pause`, `napkin-pull`

하은 이름 호칭은 `yuriKnowsRelationship === true`일 때만 사용하는 명시적 route adaptation이다. 원문 source 좌표가 붙은 문자열을 수정한 것처럼 기록하지 않고 별도 대사로 생성하여 원본 잠금 계약을 보존한다.

## 검증

- 3개 저장 스키마를 포함한 기존 DAY 18 결정적 경로 검사를 유지한다.
- 유리의 하은 인지 여부별 질문, 냅킨→질문→컵 순서, 흔들림/거짓 자유 발언의 행동 cue를 검사한다.
- 하은의 유리 관련 이력 유무별 냅킨 cue 배타성과 선택 9 세 반응의 cue를 검사한다.
- 행동 문장이 일반 대화·독백에 출력되지 않는지, cue 정리·CSS·캐시 버전을 검사한다.

실제 브라우저에서 유리 경로를 비-SKIP으로 행동 순서까지 재생하고, 수정 뒤 SKIP 전환으로도 `하은 씨` 질문과 선택지를 확인했다. 이 과정에서 컵 행동의 접근성 이름이 선택지에 잔존하는 결함을 발견해 선택 UI를 열기 전에 모든 행동 cue와 접근성 이름을 정리하도록 수정했다. 하은 경로에서도 냅킨·표정 행동이 일반 대사로 출력되지 않고 선택지에 잔존하지 않음을 확인했으며, 테스트용 저장은 복원했다. 전체 자동 회귀는 499/499 PASS, `npm test`도 PASS다. 이후 SCENE 11 겉옷은 실제 RGBA 자산으로 해소됐다. 다음은 동일 버전 4경로·모바일 최종 QA다.
