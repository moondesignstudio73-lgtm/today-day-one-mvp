# DAY18 당일 대화 연기 — 구현 계획 2026-09-04 21:06

원문 근거: SCENE17, 함께 저녁을 먹은 뒤 “생각이 남았다고 말한다”의 피곤해서 내일 듣고 싶다는 응답과 가능한 시간 질문. 조건의 발동 확률/호감도 임계값은 원문에 없다. 해당 선택의 새 버전에서는 하은이 현재 피곤함을 직접 말하는 것으로 구체화한다. 과거 피로 이력을 날조하거나 연락 허용을 호감으로 바꾸지 않는다. 유리 저녁 후 통화와는 독립된 첫 연기 경로다.

## 입력·출력 및 호환성

- 기존 `day18-notion-v4/1`은 입력·선택 그래프·반응을 그대로 유지한다. 자동 마이그레이션/저장 초기화 없음.
- 새 실제 게임 진입만 `callScheduling:true`를 동결하고 `/2`로 시작한다. 직접 계약 API의 기본은 `/1` 유지. 검증은 스키마와 동결 입력의 일치를 요구한다.
- `/2`, 실제 HAEUN 식사, `night_thought`에서 `night_schedule`로 이동. 하은이 피곤함을 말하고, 내일 저녁 이후를 제안받아 수락하거나 정확한 시간은 내일 다시 묻도록 한다.
- `schedule_after_dinner`: 문자 제안 + 하은의 수락, 연락 DAY19, 시간창 AFTER_DINNER. 정확한 시각은 미정이며 예약/여행/데이트를 생성하지 않는다.
- `schedule_ask_tomorrow`: 주인공의 DAY19 연락 약속만 기록, 상호 시간 합의는 없음.
- 후속 계약은 선택에서 도출한다. 기존 `followUpContact` boolean을 동의로 해석하지 않는다. 새 facts의 `callDeferred:true`는 당일 긴 대화를 하지 않았음을 나타낸다.

## Scene Graph

HAEUN 실제 식사 → night_thought의 짧은 사실 전달 → 하은의 당일 피곤함 응답 → 시간 협의 선택 → 실제 문자 응답 → 혼자 밤 마무리 → 혼자 여행 후보 탐색 → 합의/미합의에 맞는 끝맺음.

관계 갈등이 있으면 다음으로 미뤄질 뿐 해결된 것으로 바꾸지 않는다. 당일 관계 통화나 평온한 여행 통화를 이어 붙이지 않는다. 하은 스프라이트는 방에 나타나지 않는다. Free 행동 선택과 섞지 않는다.

## 검증

구/신 버전 동일 선택의 서로 다른 정당한 재생, 구 버전 저장 불변, 버전-입력 위조 거부, 두 협의 선택의 서로 다른 계약, 연락 휴식/유리/짧은 인사 비영향, 실제 SaveManager, 실제 브라우저 문자→협의→저장 재개→후속 장면 확인. 전체 DAY18 완료 판정은 별도다.

- 별도 재진입에서 시간 미정 선택 → “지금 시간을 정하기는 어렵네. 내일 물어봐 줘.” → 혼자 마무리 확인. 기존 사용자 저장 복원 성공. 대화창 밖으로 잘림/하은 방 동석/Free 메뉴 난입은 관찰되지 않았다.
- 기존 후속 계약 문서의 모든 `agreedTime:null` 설명은 `/1` 기준이다. `/2`에서 `schedule_after_dinner`만 `{day:19,window:AFTER_DINNER}`이며 정확한 시각과 여행 동의는 여전히 없다.
