# 스토리 문자 표현

기존 보라색 대화창과 고운돋움 글꼴을 유지하면서 문자만 작은 수신/발신 말풍선으로 구분한다. 별도 앱 같은 전체 화면을 추가하지 않고 기존 진행 입력·선택·저장을 유지한다.

- 색: 무대 `#17131f`, 수신 `#343044`, 발신 `#624256`, 글자 `#fff7fb`, 초점 `#ffbcc9`.
- 글꼴: 기존 Gowun Dodum 본문, 기존 Outfit 이름표. 본문 크기는 기존 반응형 크기 유지.
- 배치: 데스크톱 하단 오른쪽에 최대 480px 폭, 선택지는 기존 왼쪽. 모바일 하단 전체 폭 안에서 좌우 여백만 다르게 둔다.
- 전달 정보: 이름표의 `문자` 표시와 발신/수신 위치. 장식용 스마트폰 프레임이나 실제 연락처 번호는 넣지 않는다.
- 검토: 새로운 대시보드 형태가 아니라 기존 VN의 문자 장면 구분에만 쓰며, 선택·일반 독백으로 넘어가면 문자의 형태가 남지 않아야 한다. 긴 문장은 고정 높이로 자르지 않는다. 추가 자동 애니메이션 없음.
