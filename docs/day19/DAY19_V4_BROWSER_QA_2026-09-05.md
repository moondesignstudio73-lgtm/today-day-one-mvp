# DAY 19 V4 실제 브라우저 QA

## QA 계약

- 실제 `index.html`과 본선 `game.js`를 로컬 서버에서 실행한다.
- 경로 fixture는 테스트 시작 전 Story/Free/공용 저장 키를 세션에 한 번 백업하고 종료 뒤 명시적으로 복원한다.
- SKIP 버튼은 사용하지 않는다. 화면에 나타난 모든 대화·문자·독백을 진행하고 각 선택을 실제 버튼으로 누른다.
- Friendly/Neutral/Distant/Mixed는 별도 실행으로 검증하며 자동 순수 함수 검사를 실제 플레이 증거로 합산하지 않는다.
