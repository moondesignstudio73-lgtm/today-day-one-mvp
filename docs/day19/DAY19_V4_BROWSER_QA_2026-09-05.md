# DAY 19 V4 실제 브라우저 QA

## QA 계약

- 실제 `index.html`과 본선 `game.js`를 로컬 서버에서 실행한다.
- 경로 fixture는 테스트 시작 전 Story/Free/공용 저장 키를 세션에 한 번 백업하고 종료 뒤 명시적으로 복원한다.
- SKIP 버튼은 사용하지 않는다. 화면에 나타난 모든 대화·문자·독백을 진행하고 각 선택을 실제 버튼으로 누른다.
- Friendly/Neutral/Distant/Mixed는 별도 실행으로 검증하며 자동 순수 함수 검사를 실제 플레이 증거로 합산하지 않는다.

- C1 하은 문의, shared C5, 공동 C8, 두 사람 C11, 함께 먹기/내일 초대 C13, shared C14, C15, 합의 금액 C16은 화면에 나타나지 않았다.
- DAY20 선택 화면까지 SKIP 없이 완주했다. 전 구간 하은 인물 스프라이트 노출 0, console warning/error 0.
- DAY20에서 `storyState=STORY_CHOICE`, Story 선택 표시, Free Action 숨김. 데스크톱 `1484×799`, `scrollWidth=1484`: 가로 넘침 0.

- presentation 필터 회귀는 기존 replay 옵션 세 개를 그대로 인정해 공개 직전 저장 호환성을 보존한다.

## Mixed — PASS (game249)

- 입력: 하은 연락 가능/solo 계획, DAY18 밤 연락을 내일로 미룬 실제 이력, DAY12 서진 개인 초대·원칙적 수락 이력, 사전 오락비 있음.
- 최초 Mixed fixture는 연락 가능 DAY18 경로에서 disclosure와 night 선택을 생략해 `menu_familiar`, `alone_stop`이 거부됐다. 사용자 저장을 변경하기 전에 멈췄고, `disclose_solo → night_defer → alone_stop`을 포함한 합법 replay로 교정했다.
- 교정 뒤 새 클린 탭에서 실제 선택: 하은의 하루 문의 → 짧은 여행 비교 → 오락비 안 복권 1회 → 민호에게 예상 시간 문의 → 개인 우선 지출 → 늦은 출발 → 관계를 편하게 하고 싶은 마음 → 서로 원하는 것 추가 → 풍경 → 부산 1박 후보 → 후보 유지 → 아쉬움 인정 → 내일 집 식사 제안 → 혼자 먹을 것 하나 → 서진 연락에 시간 요청 → 생활비 보존.
- 내일 식사 제안은 shared 수락으로 승격되지 않고 solo C14가 표시됐다. C15는 실제 서진 미완료 연락 때문에 나타났으며, 화면에는 존재하지 않는 유리·아라 이름을 넣지 않았다. solo C11은 후보 유지 하나, solo C16은 합의 금액 없이 두 선택만 노출됐다.
- 실제 UI에서 복권 선택은 한 번만 눌렀고 결과·등급·상금 표현은 끝까지 나타나지 않았다. 정확한 5,000원 1회 원장 반영과 `prizeCounted:false`는 브리지 자동 원자성 검사로 별도 확인했다. Story 화면의 숨겨진 자산 카드는 진행 중 갱신 증거로 사용하지 않았다.
- 16개 선택을 SKIP 없이 DAY20까지 완주했다. 전 구간 대면 인물 스프라이트 노출 0, console warning/error 0.
- DAY20에서 `storyState=STORY_CHOICE`, Story 선택 표시, Free Action 숨김. 데스크톱 `1484×799`, `scrollWidth=1484`: 가로 넘침 0.
- 클린 탭 테스트 종료 뒤 `테스트 전 저장을 복원했습니다.`를 확인했다.
