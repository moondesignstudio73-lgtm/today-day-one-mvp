# DAY18 SCENE01 — 혼자 선택의 누락 독백

2026-09-05 01:09 실행, game212. DAY18 PARTIAL.

## 원문 대조와 구현

알람/옷 행동을 위한 SCENE01 재검토 중 혼자 분기의 내적 반응 누락을 확인했다. “오늘 저녁이 혼자라는 사실이 누군가에게 보여 줄 선언일 필요도 없었다.”를 약속 없이 혼자 선택했을 때 냉장고 CG 직전에 복구했다. 이 문장은 물리 행동이나 개발 메모가 아닌 내적 생각이다.

입력/출력 계약과 저장 스키마는 변경하지 않는다. 기존 `appointmentCancelled`가 false인 분기만 사용한다. 기존 약속을 취소하는 YURI/HAEUN에는 취소 문자가 그대로 나오며 이 독백은 붙이지 않는다. 누구에게도 연락하지 않았다는 새로운 과거 사실은 만들지 않는다.

흐름: 약속 없는 혼자 선택 → 내적 생각 → 냉장고 CG → 저녁에 대한 독백 → 기존 다음 장면. 알람/발끝/옷 꺼내기 연출을 이 텍스트 복구로 완료 처리하지 않는다.

## 검증

- 전체 자동 테스트 468 PASS, 0 FAIL. 신규 검사는 3개 저장 스키마 × 3개 약속 유형의 조건, 취소 여부, 독백/CG 순서, 렌더 순수성 및 JSON 재생을 확인한다.
- 실제 앱 브라우저의 별도 QA 저장에서 SOLO 아침을 SKIP 없이 진행했다. 선택 뒤 새 독백이 일반 내적 대화 패널/08:00에 표시되고, 다음 입력에 냉장고 CG가 표시된 뒤 기존 독백으로 돌아왔다.
- 새로고침 → 이어하기에서 같은 새 독백으로 Scene 재개를 확인했다. 콘솔 오류/경고 조회는 비어 있었다. 같은 QA 탭의 복원 버튼으로 사용자 저장을 복원했다.
- 유지/취소 전체 브라우저 경로와 동일 최종 버전 4경로 및 모바일 검증을 이번 실행에서 수행한 것으로 집계하지 않는다.
