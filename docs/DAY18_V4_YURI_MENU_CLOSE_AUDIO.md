# DAY 18 V4 — 유리 각자 메뉴 닫힘 두 번

## 원문과 구현

- 원문: `그녀의 선택과 내 선택은 달랐다. 메뉴판을 덮는 소리가 두 번 났다. 같은 것을 고르지 않았는데도 한 끼가 시작됐다.`
- 분류: 두 사람이 각각 메뉴를 닫는 물리·음향 행동과 그 뒤 내적 반응이다.
- 적용 범위: 실제 저녁 상대가 유리이고 `각자 고른다(menu_each)`를 선택한 경우만 실행한다.
- 순서: 유리와 주인공이 각 메뉴를 말한 뒤 종이 커버 취급 효과음→180ms 간격→같은 효과음을 한 번 더 재생하고 원문 내적 반응으로 이어진다.
- 자산: 기존 `assets/audio/day2/document-receive.wav`를 메뉴 커버의 짧은 종이·표지 취급음으로 재사용한다. 새 대사나 상태는 추가하지 않는다.

## 검증

- 자동: 3개 저장 스키마 × 유리/하은 × 세 메뉴 선택에서 유리 `menu_each`에만 두 효과음과 180ms 간격이 나타나는지 검사했다.
- 원문 행동 문장 자체가 일반 독백으로 출력되지 않고, 가장 가까운 앞 대사가 `저는 이걸로요.`, 뒤가 원문 내적 반응인지 확인했다.
- 오디오 자산 존재, 상태 불변, 결정적 재생을 검사했다.
- 전체 회귀: 485 PASS, 0 FAIL.
- 실제 비-SKIP: 사운드를 켠 집중 fixture에서 두 메뉴 대사→두 SFX cue 구간→원문 내적 반응을 진행했고 콘솔 오류·경고는 없었다. 자동 테스트는 cue 두 번과 간격을 검증하지만 이 기록은 파형·음량의 독립 청감 측정 증거는 아니다.
- 사용자 저장: 테스트 전 저장으로 복원 완료.

## 판정

원문의 두 번 닫힘 cue는 연결했다. 알람 입력·소리, 동일 버전 4경로·모바일·DAY15~17 감사가 남아 DAY18은 `PARTIAL`이다.
