# DAY18 유리 저녁 후 통화 협의 — 2026-09-04 21:17

## 원문 및 상태 계약

SCENE17은 만난 사실을 알린 뒤 하은이 통화 가능 여부를 먼저 답하고, 불가하면 짧은 문자와 합의한 후속 시간으로 옮기도록 한다. 현재는 목적/재만남 요청까지 모두 문자로 보낸 뒤에야 가능 여부를 묻는다. 이 순서를 먼저 바로잡는다.

원문에는 불가 조건의 수치가 없다. 새 버전의 구체화: 유리 약속을 사전에 알리지 않은 경로에서 하은은 방금 처음 들은 저녁을 즉시 긴 통화로 받기 어렵다고 현재 자기 뜻을 말한다. 과거 피로/일정/감정을 추정하지 않는다. 사전 공유 경로는 기존 당일 통화를 유지한다. 이는 실제 발언 이력에 따른 원문 조건의 연출 선택이며 호감도 벌점이 아니다.

- 새 게임 진입만 `separateDinnerScheduling:true`를 동결하여 `/3` 시작. `/1`, `/2`는 원래 선택 그래프 유지; 저장 자동 마이그레이션 없음.
- 입력: `callScheduling:true`, `separateDinnerScheduling:true`, 실제 YURI 식사, night_tell, 이전 하은의 약속 인지 또는 진실한 낮 고지 기록.
- 미고지 경로: 만난 사실 문자 → 통화 요청 → 하은 불가 응답 → 실제 목적/재만남 의향을 짧게 문자로 전달 → 기존 night_schedule → 두 시간 협의 선택 → 혼자 마무리. 당일 관계 통화/평온 여행 통화 없음.
- 사전 고지 경로: 만난 사실 문자 → 요청/수락 → 목적/재만남 의향을 통화 자막으로 전달 → SCENE18 관계 선택. 요청을 상대의 재만남 동의로 바꾸지 않는다.
- 출력: 기존 사실 고지/statement 그대로, 불가 시 callDeferred와 DEFERRED, 실제 협의 선택에서만 시간창 합의. 유리에게도 새 약속을 만들지 않는다.
