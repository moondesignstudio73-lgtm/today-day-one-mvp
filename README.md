# 오늘부터 1일: Thirty Days

30일 동안 사랑, 일, 돈, 건강과 인간관계를 선택하며 자신만의 이야기를 만드는 연애 라이프 시뮬레이션 HTML5 프로토타입입니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

로컬 서버를 사용할 경우:

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다.

## 구현된 기능

- DAY 1부터 DAY 30까지 아침·낮·저녁·밤 행동 선택
- 13개 수치 조합으로 매 게임 달라지는 연인 성격
- 반복된 행동에서 단서를 쌓아 공개되는 숨겨진 성향
- 성향 공개 전 실제 반응을 표본으로 보여주는 불확실한 추정 힌트
- 저장 시 연인 성향 13개와 수치 범위를 검사하는 데이터 검증
- 상태 조건·확률·우선순위·쿨다운을 조합하는 이벤트 시스템
- 플레이어 상태와 연인 성격에 따라 변화하는 이벤트 발생 확률
- 사건 과밀을 막는 하루 최대 1개 이벤트 제한
- 최근 야근·데이트·유혹 행동이 후속 사건 확률에 미치는 연쇄 결과
- 애정·신뢰·갈등과 충성도·기회주의가 만드는 이별 위기 및 라이벌 사건
- 갑작스러운 야근·전 연인 연락·데이트 취소 랜덤 사건
- 이벤트 ID·조건·확률·쿨다운·효과를 검사하는 데이터 스키마 검증
- 내부 능력치·13개 성향·이벤트 확률과 쿨다운을 보여주는 디버그 패널
- 화면 로직과 분리된 4개 시간대·16개 행동 데이터 테이블
- 돈·체력 등 상태에 따른 행동 요구조건과 잠금 사유 표시
- 연인의 연락·낭만·물질·질투 성향에 따라 달라지는 행동 결과
- 호감·신뢰·설렘·갈등 조합으로 표시되는 7가지 관계 상태
- 호감도와 신뢰도의 분리 관리
- 돈, 체력, 건강, 스트레스, 매력, 업무 능력, 사회성
- 데이트, 연락, 업무, 투자, 쇼핑, 유혹 등 상호 연결된 행동
- 관계 상태에 따라 달라지는 채팅 반응
- 자동 저장과 수동 저장/불러오기
- 누적 선택과 수치에 따른 멀티 엔딩
- 데스크톱과 모바일 반응형 UI

## 테스트

```bash
npm test
```

100개의 서로 다른 초기 상태로 30일(각 120회 행동)을 자동 진행해 종료 조건, 능력치 범위, 엔딩 생성과 저장 데이터 복원을 검증합니다.
