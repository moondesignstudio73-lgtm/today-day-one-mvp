# 오늘부터 1일: Thirty Days

30일 동안 사랑, 일, 돈, 건강과 인간관계를 선택하며 자신만의 이야기를 만드는 연애 라이프 시뮬레이션 HTML5 프로토타입입니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

로컬 서버를 사용할 경우:

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다.

## 구현된 기능

- DAY 1부터 DAY 30까지 아침·낮·저녁·밤 행동 선택
- 13개 수치 조합으로 매 게임 달라지는 연인 성격
- 반복된 행동에서 단서를 쌓아 공개되는 숨겨진 성향
- 성향 공개 전 실제 반응을 표본으로 보여주는 불확실한 추정 힌트
- 저장 시 연인 성향 13개와 수치 범위를 검사하는 데이터 검증
- 상태 조건·확률·우선순위·쿨다운을 조합하는 이벤트 시스템
- 플레이어 상태와 연인 성격에 따라 변화하는 이벤트 발생 확률
- 사건 과밀을 막는 하루 최대 1개 이벤트 제한
- 최근 야근·데이트·유혹 행동이 후속 사건 확률에 미치는 연쇄 결과
- 애정·신뢰·갈등과 충성도·기회주의가 만드는 이별 위기 및 라이벌 사건
- 갑작스러운 야근·전 연인 연락·데이트 취소 랜덤 사건
- 이벤트 ID·조건·확률·쿨다운·효과를 검사하는 데이터 스키마 검증
- 내부 능력치·13개 성향·이벤트 확률과 쿨다운을 보여주는 디버그 패널
- 화면 로직과 분리된 4개 시간대·16개 행동 데이터 테이블
- 돈·체력 등 상태에 따른 행동 요구조건과 잠금 사유 표시
- 연인의 연락·낭만·물질·질투 성향에 따라 달라지는 행동 결과
- 호감·신뢰·설렘·갈등 조합으로 표시되는 7가지 관계 상태
- 수입·스트레스·성장성·사회 기회가 다른 4개 직업과 승진 시스템
- 승진 진행도, 예상 급여와 직업 특성을 보여 주는 커리어 UI
- 매일 생활비와 DAY 10·20·30 급여를 기록하는 경제 원장
- 누적 수입·지출·순손익, 다음 급여일과 최근 거래를 보여 주는 재정 UI
- 업무·데이트·쇼핑 등 선택 행동의 수입과 지출을 자동 기록하는 원장 연동
- 랜덤 사건과 주기적 성과급·긴급지출까지 추적하는 이벤트 경제 기록
- 가상 브랜드 아이템 8개와 인벤토리·카테고리별 장착 기반
- 장착 보너스를 유효 매력·패션과 데이트 호감 효과에 반영
- 소유자·보너스·장착 상태를 확인하고 장비를 교체하는 가방 UI
- 의류·향수·화장품·스마트폰 등 8개 아이템을 내 것 또는 선물용으로 구매하는 상점 UI와 지출 원장
- 연인 성향별 선물 반응과 선호 아이템 자동 장착
- 가방의 선물 대기 아이템을 직접 전달하고 반응을 기록하는 선물 UI
- 운동·업무·쇼핑·수면에 연결된 피로·패션·자신감 자기관리
- 피로 70 이상에서 업무·사회·관계 효율 저하와 스트레스 부담 증가
- 자신감 70 이상에서 사회·관계 성과 상승과 스트레스 부담 완화
- Phase 4 기반: 동료·친구·상사·라이벌 NPC 랜덤 생성과 관계 수치 저장 검증
- 동료 식사·술자리·업무 행동이 NPC 호감·신뢰·관심도와 관계 기록에 누적
- 유혹 단계와 라이벌 접근 위험을 표시하는 인맥 UI
- 여성 동료의 접근에 거절·친구 유지·비밀 만남으로 대응하는 유혹 분기
- 관계 취약도·연인 성향·경제 상태·라이벌 매력을 종합한 접근 위험 계산
- 호감·신뢰·갈등·관계 스트레스와 성향을 종합한 조기 이별 판정
- Phase 5 기반: 성향·관계·최근 행동·사건·선물·유혹·경제 상태를 묶는 AI 대화 컨텍스트
- 중요도 기반으로 행동·사건·선물·유혹을 보존하고 대화에 전달하는 장기 기억
- 연락 성향·관계·최근 행동에 따라 확률과 문구가 달라지는 여자친구 선제 메시지
- 자유 입력과 상태·기억 기반 동적 답변, 대화 기록 저장을 지원하는 채팅 UI
- API 키를 노출하지 않는 외부 AI 백엔드 엔드포인트 어댑터와 로컬 응답 폴백
- Phase 6 기반: 위험·변동성·추세가 다른 가상 종목과 일일 가격 변동 기록
- 1주 단위 매수·매도, 평균 매입가·보유 수량·평가손익과 경제 원장 연동
- 하루 3장 제한 즉석복권, 확률형 당첨 등급·누적 손익과 경제 원장 연동
- 현금·저축·주식 평가액을 합산한 총자산, 저축 입출금과 일일 이자
- Phase 7 기반: 선택 성향·관계·총자산·커리어·위험 기록을 요약하는 30일 엔딩 리포트
- 관계·배신·라이벌·경제·주식·복권 기록을 우선순위로 판정하는 14개 다중 엔딩
- Phase 8 기반: 설정이 유지되는 효과음 토글과 선택·확정·경고·엔딩 사운드 피드백
- 키보드 초점 진입·순환·복귀와 Escape 닫기를 지원하는 접근성 모달
- 화면·패널·모달 전환 애니메이션과 동작 줄이기 운영체제 설정 지원
- 200회 자동 플레이에서 엔딩 다양성과 최다 결과 비율을 감시하는 균형 회귀 검사
- 호감도와 신뢰도의 분리 관리
- 돈, 체력, 건강, 스트레스, 매력, 업무 능력, 사회성
- 데이트, 연락, 업무, 투자, 쇼핑, 유혹 등 상호 연결된 행동
- 관계 상태에 따라 달라지는 채팅 반응
- 자동 저장과 수동 저장/불러오기
- 누적 선택과 수치에 따른 멀티 엔딩
- 데스크톱과 모바일 반응형 UI

## 테스트

```bash
npm test
```
